# BehgodAllTheThings

An Open-Source Cybersecurity Learning Project.

## About

A free educational resource designed to teach cybersecurity
from absolute beginner to advanced security research.

## Our Mission

Make cybersecurity education accessible to everyone.

## Learning Philosophy

- Understand the fundamentals.
- Learn by doing.
- Explore how systems work internally.
- Develop independent problem-solving skills.
