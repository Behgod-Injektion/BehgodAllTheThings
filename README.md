# BehgodAllTheThings

**دانشنامه آزاد علوم کامپیوتر و امنیت سایبری**

BehgodAllTheThings یک پروژه آموزشی رایگان و متن‌باز است که با رویکردی بنیادی و ساختاریافته، مسیر یادگیری را از مبانی علوم کامپیوتر تا امنیت سایبری و پژوهش تخصصی دنبال می‌کند.

هدف ما فقط آموزش ابزارها نیست؛ می‌خواهیم سازوکار داخلی سیستم‌ها را بفهمیم، ریشه آسیب‌پذیری‌ها را تحلیل کنیم و توانایی حل مسئله و پژوهش مستقل را پرورش دهیم.

## شروع یادگیری

**[ورود به دانشنامه فارسی](https://behgod-injektion.github.io/BehgodAllTheThings/)**

نسخه فارسی، زبان اصلی پروژه در مرحله فعلی است. نسخه انگلیسی در برنامه توسعه آینده قرار دارد.

## حوزه‌های آموزشی

- مبانی علوم کامپیوتر، ریاضیات و برنامه‌نویسی
- معماری کامپیوتر و سیستم‌عامل
- شبکه و فناوری‌های وب
- مبانی امنیت سایبری و رمزنگاری
- امنیت تهاجمی و دفاعی
- مهندسی معکوس و تحلیل بدافزار
- توسعه اکسپلویت و پژوهش آسیب‌پذیری
- امنیت موبایل، زیرساخت، سخت‌افزار و Web3
- امنیت هوش مصنوعی و یادگیری ماشین

## اصول آموزشی

- **مبانی قبل از تخصص:** آموزش هر موضوع با پیش‌نیازهای لازم.
- **درک به‌جای حفظ‌کردن:** تمرکز بر چرایی و چگونگی عملکرد سیستم‌ها.
- **نظریه همراه با عمل:** مثال، آزمایشگاه و تمرین قابل بازتولید.
- **حل مسئله مستقل:** پرورش توانایی تحلیل مسائل جدید.
- **دقت علمی:** کیفیت و صحت فنی مهم‌تر از سرعت انتشار است.

## English

BehgodAllTheThings is a free, open-source educational project covering computer science and cybersecurity, from foundational concepts to advanced security research.

The project emphasizes understanding how systems work internally, learning through reproducible practice, and developing independent problem-solving skills. Persian is the primary language for the current phase; an English edition is planned for a later stage.

**Learn. Understand. Build. Research.**
