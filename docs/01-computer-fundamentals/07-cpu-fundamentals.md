# 07. مبانی پردازنده (CPU Fundamentals)

## معرفی

CPU دستورالعمل‌های ماشین را اجرا می‌کند. در این درس مدل مفهومی پردازنده، اجزای اصلی آن و چرخه اجرای دستورالعمل را می‌شناسیم.

## اهداف یادگیری

- توضیح نقش CPU
- تفکیک وظایف ALU و Control Unit
- توضیح Register
- شرح چرخه Fetch، Decode و Execute

## پیش‌نیازها

درس‌های What Is a Computer?، Computer Hardware و Data Representation توصیه می‌شوند.

## سرفصل‌ها

1. وظیفه و جایگاه CPU
2. Arithmetic Logic Unit (ALU)
3. Control Unit
4. Registers
5. Clock و محدودیت برداشت ساده از فرکانس
6. Instruction Cycle
7. Fetch، Decode و Execute
8. Instruction و Operand
9. Instruction Set مقدماتی
10. مدل مفهومی در برابر پیاده‌سازی واقعی پردازنده

## محدوده درس

Pipeline، Out-of-Order Execution، Branch Prediction، Microarchitecture و جزئیات ISA در Computer Architecture بررسی می‌شوند.

## تمرین‌ها

1. چرخه Fetch-Decode-Execute را به شکل نمودار رسم کنید و توضیح دهید چرا فرکانس بالاتر به‌تنهایی معیار عملکرد نیست.

## آزمایش عملی

مشخصات پردازنده سیستم خود را مشاهده و مدل، معماری و تعداد هسته‌های گزارش‌شده را ثبت کنید.

## منابع تکمیلی

منابع معتبر و ارجاعات دقیق هنگام نگارش نسخه کامل این درس افزوده خواهند شد.
