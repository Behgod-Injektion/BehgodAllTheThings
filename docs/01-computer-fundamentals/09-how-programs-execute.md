# 09. نحوه اجرای برنامه‌ها (How Programs Execute)

## معرفی

کدی که برنامه‌نویس می‌نویسد معمولاً مستقیماً توسط CPU اجرا نمی‌شود. این درس مسیر کلی از کد منبع تا اجرای برنامه را توضیح می‌دهد.

## اهداف یادگیری

- تفکیک Source Code و Executable
- تفکیک نقش Compiler، Assembler و Linker
- شرح وظیفه Loader
- ترسیم مراحل کلی ساخت و اجرای برنامه
- توضیح مقدماتی تفاوت Program و Process

## پیش‌نیازها

درس‌های What Is a Computer?، CPU Fundamentals و Memory and Storage توصیه می‌شوند.

## سرفصل‌ها

1. Source Code و زبان‌های برنامه‌نویسی
2. Compilation در برابر Interpretation
3. Compiler
4. Assembler
5. Object File
6. Linker و کتابخانه‌ها
7. Executable File
8. Loader
9. آغاز اجرای برنامه و تعامل با سیستم‌عامل
10. Program در برابر Process

## محدوده درس

جزئیات ELF و PE، Dynamic Linking، ABI، System Calls و Process Memory Layout در بخش‌های تخصصی‌تر بررسی می‌شوند.

## تمرین‌ها

1. مسیر تبدیل یک فایل C به فایل اجرایی را ترسیم و تفاوت Linker و Loader را توضیح دهید.

## آزمایش عملی

یک برنامه کوتاه C را در Linux به مراحل جداگانه کامپایل، تولید Object File و لینک‌کردن تقسیم و خروجی هر مرحله را بررسی کنید.

## منابع تکمیلی

منابع معتبر و ارجاعات دقیق هنگام نگارش نسخه کامل این درس افزوده خواهند شد.
