# 10. آشنایی با کد ماشین (Introduction to Machine Code)

## معرفی

CPU دستورالعمل‌هایی را اجرا می‌کند که به شکل کد ماشین رمزگذاری شده‌اند. این درس نخستین ارتباط میان نمایش بیتی، دستورالعمل و اسمبلی را ایجاد می‌کند.

## اهداف یادگیری

- تعریف Machine Code، Instruction و Opcode
- توضیح نقش Operand
- بیان تفاوت کد ماشین و اسمبلی
- شرح مفهوم ISA
- شناخت تفاوت کلی x86-64 و ARM

## پیش‌نیازها

درس‌های Number Systems، Data Representation و CPU Fundamentals الزامی یا قویاً توصیه می‌شوند.

## سرفصل‌ها

1. Machine Code چیست؟
2. Instruction و Opcode
3. Operand
4. Instruction Encoding
5. Assembly Language
6. Assembler و Disassembler
7. ارتباط ISA با Machine Code
8. آشنایی کلی با x86-64 و ARM
9. مشاهده دستورالعمل و بایت‌های متناظر
10. محدودیت‌های نگاه صرفاً بایتی به کد ماشین

## محدوده درس

رمزگذاری دستورالعمل‌ها، رجیسترها، Calling Convention، اسمبلی و تحلیل فایل‌های اجرایی در Computer Architecture و Reverse Engineering عمیق‌تر بررسی می‌شوند.

## تمرین‌ها

1. تفاوت Machine Code و Assembly را توضیح دهید و اجزای Opcode و Operand را در یک دستورالعمل مشخص کنید.

## آزمایش عملی

یک برنامه کوچک را کامپایل و با objdump یا disassembler چند دستورالعمل را در قالب اسمبلی و بایت‌های ماشین مشاهده کنید.

## منابع تکمیلی

منابع معتبر و ارجاعات دقیق هنگام نگارش نسخه کامل این درس افزوده خواهند شد.
