# 05. نمایش داده در کامپیوتر (Data Representation)

## معرفی

یک الگوی بیت به‌تنهایی نوع داده را مشخص نمی‌کند. این درس قراردادهای نمایش اعداد، نویسه‌ها و مقادیر اعشاری را بررسی می‌کند.

## اهداف یادگیری

- مقایسه نمایش Signed و Unsigned
- مقایسه روش‌های نمایش اعداد علامت‌دار
- محاسبه بازه مقادیر با عرض بیت ثابت
- توضیح ASCII، Unicode، UTF-8، IEEE 754 و Endianness

## پیش‌نیازها

درس‌های Number Systems و Binary Arithmetic الزامی هستند.

## سرفصل‌ها

1. عرض بیت و بازه مقادیر
2. Unsigned Integers
3. Signed Integers
4. Sign-Magnitude
5. One's Complement
6. Two's Complement
7. Sign Extension و Zero Extension
8. Character Encoding، ASCII و Unicode
9. UTF-8
10. Floating-Point و IEEE 754
11. Endianness: Little-Endian و Big-Endian

## محدوده درس

جزئیات دستورالعمل‌های خاص پردازنده و ABI در بخش‌های تخصصی‌تر بررسی می‌شود.

## تمرین‌ها

1. بازه 8 بیت Signed و Unsigned را محاسبه و مقدار منفی 13 را با Two's Complement در 8 بیت نمایش دهید.

## آزمایش عملی

با Python از int.to_bytes() و int.from_bytes() برای مشاهده اثر Endianness استفاده کنید.

## منابع تکمیلی

منابع معتبر و ارجاعات دقیق هنگام نگارش نسخه کامل این درس افزوده خواهند شد.
