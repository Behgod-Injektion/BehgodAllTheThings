# 08. حافظه و ذخیره‌سازی (Memory and Storage)

## معرفی

سیستم‌های کامپیوتری از چند سطح حافظه و ذخیره‌سازی با ویژگی‌ها و سرعت‌های متفاوت استفاده می‌کنند. این درس منطق کلی این سلسله‌مراتب را معرفی می‌کند.

## اهداف یادگیری

- توضیح تفاوت Memory و Storage
- تشخیص Volatile و Non-Volatile
- مقایسه سطوح اصلی Memory Hierarchy
- توضیح Locality of Reference

## پیش‌نیازها

درس‌های Data and Information و Computer Hardware توصیه می‌شوند؛ CPU Fundamentals نیز مفید است.

## سرفصل‌ها

1. Memory در برابر Storage
2. Volatile و Non-Volatile Memory
3. Registers
4. Cache
5. RAM
6. Secondary Storage
7. Memory Hierarchy
8. ظرفیت، تأخیر و پهنای باند
9. Locality of Reference
10. مفهوم آدرس حافظه

## محدوده درس

آدرس‌دهی مجازی، Page Table، Paging و مدیریت حافظه در Operating Systems بررسی می‌شوند.

## تمرین‌ها

1. سطوح حافظه را از نظر نزدیکی به CPU، سرعت و ظرفیت مقایسه کنید و Locality of Reference را با مثال توضیح دهید.

## آزمایش عملی

مصرف RAM و فعالیت ذخیره‌سازی یک برنامه را با ابزارهای سیستم‌عامل مشاهده کنید.

## منابع تکمیلی

منابع معتبر و ارجاعات دقیق هنگام نگارش نسخه کامل این درس افزوده خواهند شد.
