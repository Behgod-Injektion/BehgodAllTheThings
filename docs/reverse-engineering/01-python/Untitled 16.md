## کار با فایل‌های متنی (Writing Files)

عملگرها و متدهای رشته فقط برای دست‌کاری رشته‌های معمولی کاربرد ندارند؛ بلکه هنگام خواندن و نوشتن فایل‌های متنی هم بسیار مفید هستند.

برای درک بهتر، فرض کن می‌خواهیم با متن رمان معروف **Dracula** نوشته Bram Stoker کار کنیم. نسخه متنی این کتاب از طریق وب‌سایت Project Gutenberg در دسترس است و آن را در فایلی به نام `pg345.txt` ذخیره کرده‌ایم.

برای باز کردن فایل و خواندن محتوای آن، می‌توانیم از تابع `open()` استفاده کنیم:

!!! example "Python"

    ```python
    reader = open('pg345.txt')
    ```

اما یک نکته وجود دارد: فایل فقط شامل متن اصلی رمان نیست. در ابتدای فایل، اطلاعاتی درباره کتاب و در انتهای آن، اطلاعات مربوط به مجوز انتشار قرار گرفته است.

قبل از اینکه پردازش متن را شروع کنیم، بهتر است این بخش‌های اضافی را حذف کنیم.

برای این کار، ابتدا باید خطوط مشخص‌کننده ابتدا و انتهای متن را پیدا کنیم. این خطوط با عبارت `***` شروع می‌شوند.

می‌توانیم تابعی بنویسیم که بررسی کند آیا یک خط با عبارت مشخصی شروع شده است یا نه:

!!! example "Python"

    ```python
    def is_special_line(line):
        return line.startswith('*** ')
    ```

در این تابع از متد `startswith()` استفاده کرده‌ایم. این متد بررسی می‌کند که آیا یک رشته با دنباله مشخصی از کاراکترها شروع می‌شود یا خیر.

حالا می‌توانیم تمام خطوط فایل را یکی‌یکی بخوانیم و فقط خطوط ویژه را نمایش دهیم:

!!! example "Python"

    ```python
    for line in reader:
        if is_special_line(line):
            print(line.strip())
    ```

    **Output:**

    ```text
    *** START OF THE PROJECT GUTENBERG EBOOK DRACULA ***
    *** END OF THE PROJECT GUTENBERG EBOOK DRACULA ***
    ```

همان‌طور که می‌بینی، دو خط مشخص‌کننده ابتدا و انتهای متن را پیدا کردیم.

### ساخت فایل جدید و حذف محتوای اضافی

حالا می‌خواهیم فایل جدیدی به نام `pg345_cleaned.txt` بسازیم که فقط متن اصلی رمان را در خودش داشته باشد.

برای این کار، ابتدا باید فایل اصلی را دوباره برای خواندن باز کنیم و سپس فایل جدید را برای نوشتن ایجاد کنیم:

!!! example "Python"

    ```python
    reader = open('pg345.txt')
    writer = open('pg345_cleaned.txt', 'w')
    ```

تابع `open()` علاوه بر نام فایل، یک پارامتر اختیاری به نام `mode` هم می‌گیرد که مشخص می‌کند فایل را با چه حالتی باز کنیم.

در این مثال، مقدار `'w'` به معنی حالت نوشتن (Write) است.

رفتار این حالت به شکل زیر است:

- اگر فایل وجود نداشته باشد، ساخته می‌شود.
    
- اگر فایل از قبل وجود داشته باشد، محتوای قبلی آن جایگزین می‌شود.
    

پس هنگام استفاده از حالت `'w'` مراقب باش؛ چون ممکن است محتوای قبلی یک فایل را از دست بدهی.

اولین قدم این است که فایل را از ابتدا بخوانیم تا به اولین خط ویژه برسیم:

!!! example "Python"

    ```python
    for line in reader:
        if is_special_line(line):
            break
    ```

اینجا با دستور `break` آشنا می‌شویم.

دستور `break` باعث می‌شود حلقه بلافاصله متوقف شود؛ یعنی دیگر منتظر تمام‌شدن فایل نمی‌مانیم و اجرای حلقه را همان لحظه ترک می‌کنیم.

در این مثال، به محض اینکه اولین خط ویژه پیدا شود، حلقه متوقف خواهد شد.

حالا یک نکته جالب: بعد از خروج از حلقه، متغیر `line` همچنان در دسترس است و آخرین مقداری را نگه می‌دارد که حلقه دریافت کرده بود؛ یعنی همان خط ویژه:

!!! example "Python"

    ```python
    line
    ```

    **Output:**

    ```text
    '*** START OF THE PROJECT GUTENBERG EBOOK DRACULA ***\n'
    ```

به کاراکتر `\n` در انتهای رشته دقت کن. این کاراکتر نشان‌دهنده پایان خط (Newline) است.

اما چرا می‌توانیم حلقه دیگری اجرا کنیم و از همان‌جایی که قبلاً متوقف شدیم، خواندن فایل را ادامه دهیم؟

چون شیء `reader` موقعیت فعلی خود را در فایل نگه می‌دارد. بنابراین پس از خروج از حلقه اول، موقعیت خواندن فایل همچنان در همان نقطه باقی مانده است.

حالا می‌توانیم حلقه دوم را اجرا کنیم تا متن اصلی را بخوانیم و در فایل جدید بنویسیم:

!!! example "Python"

    ```python
    for line in reader:
        if is_special_line(line):
            break
        writer.write(line)
    ```

در این حلقه، هر خط ابتدا بررسی می‌شود:

- اگر خط ویژه باشد، یعنی به انتهای متن اصلی رسیده‌ایم؛ پس با `break` از حلقه خارج می‌شویم.
    
- در غیر این صورت، خط را با استفاده از متد `write()` در فایل خروجی می‌نویسیم.
    

به این ترتیب، فقط خطوط مربوط به متن اصلی رمان در فایل جدید ذخیره می‌شوند.

بعد از پایان حلقه، متغیر `line` شامل خط ویژه دوم خواهد بود:

!!! example "Python"

    ```python
    line
    ```

    **Output:**

    ```text
    '*** END OF THE PROJECT GUTENBERG EBOOK DRACULA ***\n'
    ```

### بستن فایل‌ها

در این مرحله، هنوز هر دو فایل باز هستند. یعنی همچنان می‌توانیم از `reader` برای خواندن و از `writer` برای نوشتن استفاده کنیم.

اما وقتی کارمان با فایل‌ها تمام شد، بهتر است آن‌ها را ببندیم. برای این کار از متد `close()` استفاده می‌کنیم:

!!! example "Python"

    ```python
    reader.close()
    writer.close()
    ```

با فراخوانی این متد، فایل‌ها بسته می‌شوند و منابعی که برای باز نگه‌داشتن آن‌ها استفاده شده بود، آزاد می‌شوند.

حالا برای اطمینان از اینکه عملیات با موفقیت انجام شده، می‌توانیم چند خط اول فایل جدید را بخوانیم:

!!! example "Python"

    ```python
    for line in open('pg345_cleaned.txt'):
        line = line.strip()

        if len(line) > 0:
            print(line)

        if line.endswith('Stoker'):
            break
    ```

    **Output:**

    ```text
    DRACULA
    _by_
    Bram Stoker
    ```

در این مثال چند نکته وجود دارد:

- با `strip()` کاراکترهای فاصله و خط جدید را از ابتدا و انتهای رشته حذف می‌کنیم.
    
- با `len(line) > 0` بررسی می‌کنیم که خط خالی نباشد.
    
- با `endswith()` بررسی می‌کنیم که آیا رشته به دنباله مشخصی از کاراکترها ختم می‌شود یا خیر.
    
- با `break` پس از رسیدن به خطی که به `Stoker` ختم می‌شود، حلقه را متوقف می‌کنیم.
    

متد `endswith()` از نظر عملکرد شبیه `startswith()` است؛ با این تفاوت که به‌جای ابتدای رشته، انتهای آن را بررسی می‌کند.

## جست‌وجو و جایگزینی (Find and Replace)

یکی دیگر از کاربردهای مهم رشته‌ها، پیدا کردن یک عبارت و جایگزین‌کردن آن با عبارت دیگری است.

برای مثال، در ترجمه‌ای ایسلندی از رمان Dracula که در سال ۱۹۰۱ منتشر شده، نام یکی از شخصیت‌ها از `Jonathan` به `Thomas` تغییر داده شده است.

حالا فرض کن می‌خواهیم همین تغییر را در نسخه انگلیسی کتاب انجام دهیم.

برای این کار، ابتدا باید بدانیم چند بار نام `Jonathan` در متن ظاهر شده است.

### شمارش تعداد خطوط فایل

اول از همه، تعداد خطوط فایل پاک‌سازی‌شده را محاسبه می‌کنیم:

!!! example "Python"

    ```python
    total = 0

    for line in open('pg345_cleaned.txt'):
        total += 1

    total
    ```

    **Output:**

    ```text
    15499
    ```

یعنی فایل ما شامل ۱۵٬۴۹۹ خط است.

در این مثال، متغیر `total` نقش شمارنده را دارد و در هر بار اجرای حلقه یک واحد به آن اضافه می‌شود.

### شمارش خطوطی که شامل یک کلمه هستند

حالا می‌خواهیم بدانیم چند خط از فایل شامل عبارت `Jonathan` هستند.

برای این کار می‌توانیم از عملگر `in` استفاده کنیم. قبلاً دیدیم که این عملگر بررسی می‌کند آیا یک دنباله از کاراکترها درون رشته دیگری وجود دارد یا خیر.

!!! example "Python"

    ```python
    total = 0

    for line in open('pg345_cleaned.txt'):
        if 'Jonathan' in line:
            total += 1

    total
    ```

    **Output:**

    ```text
    199
    ```

پس ۱۹۹ خط از فایل شامل نام `Jonathan` هستند.

اما صبر کن! آیا این عدد نشان می‌دهد که نام `Jonathan` دقیقاً ۱۹۹ بار در کل کتاب تکرار شده است؟

نه لزوماً.

چون ممکن است یک خط چند بار شامل این نام باشد. بنابراین شمارش خطوطی که حداقل یک بار این نام را دارند، با شمارش تعداد کل تکرارهای نام یکسان نیست.

برای محاسبه تعداد واقعی تکرارها، به متد `count()` نیاز داریم.

### متد count()

متد `count()` تعداد دفعاتی را برمی‌گرداند که یک دنباله مشخص از کاراکترها در یک رشته ظاهر شده است.

پس می‌توانیم کد قبلی را به این شکل تغییر دهیم:

!!! example "Python"

    ```python
    total = 0

    for line in open('pg345_cleaned.txt'):
        total += line.count('Jonathan')

    total
    ```

    **Output:**

    ```text
    200
    ```

حالا مشخص شد که نام `Jonathan` در مجموع ۲۰۰ بار در متن کتاب تکرار شده است.

تفاوت این دو روش را به خاطر بسپار:

- عملگر `in` فقط بررسی می‌کند که آیا یک عبارت در رشته وجود دارد یا نه.
    
- متد `count()` تعداد دفعات تکرار آن عبارت را در رشته محاسبه می‌کند.
    

### متد replace()

حالا که می‌دانیم چه چیزی را باید تغییر دهیم، وقت جایگزینی است.

برای این کار از متد `replace()` استفاده می‌کنیم. این متد یک دنباله از کاراکترها را پیدا می‌کند و آن را با دنباله دیگری جایگزین می‌کند.

ساختار کلی آن به این شکل است:

!!! example "Python"

    ```python
    string.replace(old, new)
    ```

- `old`: عبارتی که می‌خواهیم پیدا و جایگزین کنیم.
    
- `new`: عبارتی که قرار است جایگزین عبارت قبلی شود.
    

حالا می‌توانیم تمام موارد `Jonathan` را با `Thomas` جایگزین کنیم و نتیجه را در یک فایل جدید ذخیره کنیم:

!!! example "Python"

    ```python
    writer = open('pg345_replaced.txt', 'w')

    for line in open('pg345_cleaned.txt'):
        line = line.replace('Jonathan', 'Thomas')
        writer.write(line)
    ```

در این کد چه اتفاقی می‌افتد؟

1. ابتدا فایل جدیدی به نام `pg345_replaced.txt` را در حالت نوشتن باز می‌کنیم.
    
2. سپس تمام خطوط فایل پاک‌سازی‌شده را یکی‌یکی می‌خوانیم.
    
3. با استفاده از `replace()`، تمام موارد `Jonathan` را در هر خط با `Thomas` جایگزین می‌کنیم.
    
4. در نهایت، خط تغییر‌یافته را با `write()` در فایل جدید می‌نویسیم.
    

نتیجه، یک فایل جدید است که نسخه‌ای از رمان Dracula را در خود دارد؛ با این تفاوت که نام شخصیت Jonathan Harker در آن به Thomas تغییر داده شده است.

نکته مهم: متد `replace()` هم مانند متدهای رشته‌ای قبلی، رشته اصلی را تغییر نمی‌دهد؛ بلکه یک رشته جدید برمی‌گرداند. به همین دلیل، نتیجه آن را دوباره در متغیر `line` قرار داده‌ایم.
