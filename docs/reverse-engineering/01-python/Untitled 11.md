# Iteration and Search؛ تکرار و جست‌وجو

در سال ۱۹۳۹، نویسنده‌ای به نام Ernest Vincent Wright رمانی ۵۰ هزار کلمه‌ای با عنوان _Gadsby_ منتشر کرد که در تمام متن آن حتی یک بار هم از حرف `e` استفاده نشده بود!

شاید در نگاه اول کار ساده‌ای به نظر برسد، اما `e` یکی از پرکاربردترین حروف زبان انگلیسی است. به همین دلیل، نوشتن حتی چند کلمه بدون استفاده از این حرف هم می‌تواند دشوار باشد.

برای اینکه بهتر متوجه شویم این کار چقدر سخت است، در این فصل می‌خواهیم محاسبه کنیم چه کسری از کلمات انگلیسی حداقل یک بار حرف `e` را در خود دارند.

برای انجام این کار، از حلقه‌های `for` استفاده می‌کنیم تا بتوانیم حروف یک رشته (String) و کلمات موجود در یک فایل را یکی‌یکی بررسی کنیم. همچنین یاد می‌گیریم چطور درون یک حلقه، مقادیر متغیرها را به‌روزرسانی کنیم تا تعداد کلماتی را که شامل حرف `e` هستند بشماریم.

در این مسیر با عملگر `in` هم آشنا می‌شویم که برای بررسی وجود یک حرف در یک کلمه استفاده می‌شود. علاوه بر این، یک الگوی برنامه‌نویسی به نام **Linear Search** یا «جست‌وجوی خطی» را یاد می‌گیریم.

در پایان هم از همین ابزارها برای حل یک معمای کلمه‌ای به نام **Spelling Bee** استفاده خواهیم کرد.

## Loops and Strings؛ حلقه‌ها و رشته‌ها

در فصل سوم دیدیم که چطور می‌توانیم با استفاده از حلقه `for` و تابع `range()` یک دنباله از اعداد را نمایش دهیم:

!!! example "Python"

    ```python
    for i in range(3):
        print(i, end=' ')
    ```

    **Output:**

    ```text
    0 1 2
    ```

در این مثال از آرگومان نام‌گذاری‌شده `end` استفاده کرده‌ایم. به‌طور پیش‌فرض، تابع `print()` بعد از نمایش هر مقدار به خط بعد می‌رود؛ اما با تعیین `end=' '`، به‌جای رفتن به خط بعد، یک فاصله بعد از هر عدد قرار می‌دهد.

اما حلقه `for` فقط برای پیمایش دنباله اعداد نیست. می‌توانیم از آن برای پیمایش حروف یک رشته هم استفاده کنیم:

!!! example "Python"

    ```python
    for letter in 'Gadsby':
        print(letter, end=' ')
    ```

    **Output:**

    ```text
    G a d s b y
    ```

دقت کن که این بار نام متغیر را از `i` به `letter` تغییر دادیم.

چرا؟ چون `letter` دقیق‌تر نشان می‌دهد که متغیر به چه مقداری اشاره می‌کند. در اینجا، در هر تکرار حلقه، یکی از حروف رشته در این متغیر قرار می‌گیرد.

به متغیری که در حلقه `for` تعریف می‌شود و در هر تکرار مقدار جدیدی دریافت می‌کند، **Loop Variable** یا «متغیر حلقه» می‌گوییم.

حالا که می‌توانیم حروف یک کلمه را یکی‌یکی بررسی کنیم، می‌توانیم بفهمیم آیا کلمه شامل حرف `e` است یا نه.

!!! example "Python"

    ```python
    for letter in "Gadsby":
        if letter == 'E' or letter == 'e':
            print('This word has an "e"')
    ```

در این مثال، تمام حروف رشته بررسی می‌شوند. اگر حرف فعلی برابر `E` یا `e` باشد، پیام موردنظر نمایش داده می‌شود.

چرا هر دو حالت را بررسی کردیم؟ چون حروف بزرگ و کوچک در Python با یکدیگر متفاوت‌اند؛ بنابراین `E` و `e` دو کاراکتر متفاوت محسوب می‌شوند.

### تبدیل حلقه به تابع

قبل از ادامه، بهتر است این حلقه را داخل یک تابع قرار دهیم:

!!! example "Python"

    ```python
    def has_e():
        for letter in "Gadsby":
            if letter == 'E' or letter == 'e':
                print('This word has an "e"')
    ```

اما هنوز یک مشکل داریم: تابع ما فقط پیام نمایش می‌دهد و نتیجه مشخصی برنمی‌گرداند.

بیایید آن را به یک تابع خالص (Pure Function) تبدیل کنیم؛ تابعی که اگر کلمه شامل `e` باشد، مقدار `True` و در غیر این صورت مقدار `False` را برگرداند:

!!! example "Python"

    ```python
    def has_e():
        for letter in "Gadsby":
            if letter == 'E' or letter == 'e':
                return True

        return False
    ```

اینجا یک نکته مهم وجود دارد: اگر حرف `e` پیدا شود، تابع بلافاصله با `return True` تمام می‌شود. اما اگر حلقه تمام شود و هیچ‌کدام از حروف با `e` یا `E` برابر نباشند، اجرای تابع به `return False` می‌رسد.

حالا یک قدم دیگر جلو برویم. چرا تابع باید همیشه رشته `Gadsby` را بررسی کند؟ بهتر است کلمه موردنظر را به‌عنوان پارامتر دریافت کند:

!!! example "Python"

    ```python
    def has_e(word):
        for letter in word:
            if letter == 'E' or letter == 'e':
                return True

        return False
    ```

به این ترتیب، تابع دیگر به یک کلمه خاص محدود نیست و می‌توانیم آن را برای رشته‌های مختلف استفاده کنیم.

برای آزمایش:

!!! example "Python"

    ```python
    has_e('Gadsby')
    ```

    **Output:**

    ```text
    False
    ```

و:

!!! example "Python"

    ```python
    has_e('Emma')
    ```

    **Output:**

    ```text
    True
    ```

به همین سادگی، تابعی نوشته‌ایم که می‌تواند وجود یک حرف مشخص را در هر رشته‌ای بررسی کند.

## Reading the Word List؛ خواندن فهرست کلمات

حالا می‌خواهیم بفهمیم چه تعداد از کلمات انگلیسی شامل حرف `e` هستند.

برای این کار به یک فهرست از کلمات نیاز داریم. فهرستی که در این فصل استفاده می‌کنیم، حدود ۱۱۴ هزار کلمه معتبر برای جدول‌های متقاطع (Crossword) و بازی‌های کلمه‌ای دیگر دارد.

این فهرست در فایلی به نام `words.txt` قرار دارد که همراه با Notebook این فصل دانلود شده است.

برای خواندن فایل، از تابع داخلی `open()` استفاده می‌کنیم. این تابع نام فایل را به‌عنوان آرگومان دریافت می‌کند و یک شیء فایل (File Object) برمی‌گرداند که می‌توانیم از آن برای خواندن محتوای فایل استفاده کنیم.

!!! example "Python"

    ```python
    file_object = open('words.txt')
    ```

در اینجا، شیء فایل برگشتی از `open()` را در متغیر `file_object` ذخیره کرده‌ایم.

### متد readline

شیء فایل متدی به نام `readline()` دارد که از محل فعلی فایل شروع به خواندن می‌کند، تا زمانی که به کاراکتر خط جدید (Newline) برسد، و محتوای خوانده‌شده را به‌صورت یک رشته برمی‌گرداند.

!!! example "Python"

    ```python
    file_object.readline()
    ```

    **Output:**

    ```text
    'aa\n'
    ```

شاید متوجه شده باشی که نحوه فراخوانی `readline()` با توابعی که تا الان دیده‌ایم کمی متفاوت است.

دلیلش این است که `readline()` یک **Method** است.

متد در واقع تابعی است که به یک شیء تعلق دارد. در این مثال، متد `readline()` متعلق به شیء فایل است؛ بنابراین برای فراخوانی آن، ابتدا نام شیء را می‌نویسیم، سپس از عملگر نقطه (`.`) و در نهایت نام متد استفاده می‌کنیم:

!!! example "Python"

    ```python
    file_object.readline()
    ```

اولین کلمه موجود در فهرست، `aa` است که نام نوعی گدازه محسوب می‌شود.

اما چرا خروجی به شکل `'aa\n'` نمایش داده شد؟

چون `\n` نمایش کاراکتر خط جدید (Newline) است؛ همان کاراکتری که کلمه فعلی را از کلمه بعدی در فایل جدا می‌کند.

نکته جالب دیگر این است که شیء فایل موقعیت فعلی خود را به خاطر می‌سپارد. بنابراین اگر دوباره `readline()` را فراخوانی کنیم، محتوای بعدی فایل خوانده می‌شود، نه همان خط قبلی.

!!! example "Python"

    ```python
    line = file_object.readline()
    line
    ```

    **Output:**

    ```text
    'aah\n'
    ```

پس در اولین فراخوانی، `aa` و در فراخوانی بعدی، `aah` را دریافت کردیم.

### حذف کاراکترهای اضافی با strip

احتمالاً نمی‌خواهیم کاراکتر `\n` در انتهای هر کلمه باقی بماند. برای حذف آن می‌توانیم از متد `strip()` استفاده کنیم.

این متد متعلق به رشته‌هاست و کاراکترهای فضای خالی (Whitespace) را از ابتدا و انتهای رشته حذف می‌کند؛ از جمله فاصله‌ها، Tabها و کاراکترهای خط جدید.

!!! example "Python"

    ```python
    word = line.strip()
    word
    ```

    **Output:**

    ```text
    'aah'
    ```

همان‌طور که می‌بینی، `\n` دیگر در انتهای رشته وجود ندارد.

### خواندن فایل با حلقه for

یک نکته کاربردی دیگر هم وجود دارد: می‌توانیم خود شیء فایل را مستقیماً در یک حلقه `for` قرار دهیم.

در این حالت، حلقه فایل را خط‌به‌خط می‌خواند و در هر تکرار، خط بعدی را در اختیارمان قرار می‌دهد.

برنامه زیر تمام کلمات موجود در `words.txt` را می‌خواند و هر کدام را در یک خط نمایش می‌دهد:

!!! example "Python"

    ```python
    for line in open('words.txt'):
        word = line.strip()
        print(word)
    ```

در هر تکرار:

1. یک خط از فایل خوانده می‌شود و در متغیر `line` قرار می‌گیرد.
    
2. با استفاده از `strip()` کاراکترهای فضای خالی ابتدا و انتهای آن حذف می‌شوند.
    
3. کلمه تمیزشده در خروجی نمایش داده می‌شود.
    

حالا می‌توانیم فایل کلمات را بخوانیم و کلمات آن را یکی‌یکی بررسی کنیم.

**قدم بعدی چیست؟** می‌خواهیم تعداد کلماتی را که شامل حرف `e` هستند بشماریم. برای این کار باید یاد بگیریم چطور مقدار متغیرها را درون یک حلقه به‌روزرسانی کنیم.
