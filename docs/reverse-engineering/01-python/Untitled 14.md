# Strings and Regular Expressions؛ رشته‌ها و عبارات منظم

رشته‌ها (Strings) با انواع داده‌ای مثل `int`، `float` و `bool` تفاوت مهمی دارند.

یک رشته در واقع نوعی **Sequence** یا دنباله است؛ یعنی از چند مقدار تشکیل شده که ترتیب مشخصی دارند.

در این فصل یاد می‌گیریم چطور به عناصر تشکیل‌دهنده یک رشته دسترسی پیدا کنیم و از توابع مختلف برای پردازش رشته‌ها استفاده کنیم.

همچنین با **Regular Expressions** یا عبارات منظم آشنا می‌شویم؛ ابزاری قدرتمند برای پیدا کردن الگوها در رشته‌ها و انجام عملیاتی مثل جست‌وجو و جایگزینی (Search and Replace).

در پایان فصل هم فرصت داریم این ابزارها را در یک بازی کلمه‌ای به نام **Wordle** به کار ببریم.

---

## A String Is a Sequence؛ رشته یک دنباله است

رشته دنباله‌ای از کاراکترها (Characters) است. یک کاراکتر می‌تواند حرفی از تقریباً هر الفبا، یک رقم، علامت نگارشی یا کاراکتر فضای خالی (Whitespace) باشد.

برای دسترسی به یک کاراکتر مشخص در رشته، می‌توانیم از عملگر براکت (`[]`) استفاده کنیم.

به مثال زیر توجه کن:

!!! example "Python"

    ```python
    fruit = 'banana'
    letter = fruit[1]
    ```

در این مثال، کاراکتری را که در موقعیت شماره `1` قرار دارد از رشته `fruit` انتخاب کرده‌ایم و در متغیر `letter` قرار داده‌ایم.

مقداری که داخل براکت قرار می‌گیرد، **Index** یا «اندیس» نام دارد؛ چون مشخص می‌کند کدام کاراکتر از دنباله را می‌خواهیم انتخاب کنیم.

اما نتیجه شاید کمی غیرمنتظره باشد:

!!! example "Python"

    ```python
    letter
    ```

    **Output:**

    ```text
    'a'
    ```

چرا کاراکتر شماره `1` برابر `a` است، نه `b`؟

چون در Python شمارش اندیس‌ها از صفر شروع می‌شود، نه یک!

به عبارت دیگر، اندیس هر کاراکتر نشان‌دهنده فاصله آن از ابتدای رشته است. بنابراین فاصله اولین کاراکتر از ابتدای رشته صفر است و اندیس آن هم `0` خواهد بود.

!!! example "Python"

    ```python
    fruit[0]
    ```

    **Output:**

    ```text
    'b'
    ```

پس می‌توانیم حرف `b` را کاراکتر صفرم رشته `banana` در نظر بگیریم!

### استفاده از متغیرها و عبارت‌ها به‌عنوان اندیس

مقداری که داخل براکت قرار می‌دهیم، لزوماً نباید یک عدد ثابت باشد. می‌توانیم از یک متغیر هم استفاده کنیم:

!!! example "Python"

    ```python
    i = 1
    fruit[i]
    ```

    **Output:**

    ```text
    'a'
    ```

حتی می‌توانیم یک عبارت شامل متغیرها و عملگرها را به‌عنوان اندیس قرار دهیم:

!!! example "Python"

    ```python
    fruit[i+1]
    ```

    **Output:**

    ```text
    'n'
    ```

در اینجا ابتدا عبارت `i + 1` محاسبه می‌شود و سپس کاراکتر موجود در اندیس حاصل انتخاب می‌شود.

البته مقدار اندیس باید از نوع عدد صحیح (`int`) باشد. اگر از نوع دیگری مثل `float` استفاده کنیم، با خطا مواجه می‌شویم:

!!! example "Python"

    ```python
    fruit[1.5]
    ```

    **Output:**

    ```text
    TypeError: string indices must be integers
    ```

### به دست آوردن طول رشته با len

همان‌طور که در فصل اول دیدیم، تابع داخلی `len()` طول یک رشته را برمی‌گرداند؛ یعنی تعداد کاراکترهای موجود در آن.

!!! example "Python"

    ```python
    n = len(fruit)
    n
    ```

    **Output:**

    ```text
    6
    ```

رشته `banana` شش کاراکتر دارد.

حالا اگر بخواهیم آخرین حرف رشته را انتخاب کنیم، شاید در نگاه اول این عبارت به ذهنمان برسد:

!!! example "Python"

    ```python
    fruit[n]
    ```

    **Output:**

    ```text
    IndexError: string index out of range
    ```

اما چرا خطا گرفتیم؟

چون اندیس‌های رشته از صفر شروع می‌شوند. بنابراین اگر رشته‌ای شش کاراکتر داشته باشد، اندیس‌های آن از `0` تا `5` خواهند بود.

در نتیجه، اندیس `6` خارج از محدوده رشته است و کاراکتری در آن موقعیت وجود ندارد.

برای دسترسی به آخرین کاراکتر باید یک واحد از طول رشته کم کنیم:

!!! example "Python"

    ```python
    fruit[n-1]
    ```

    **Output:**

    ```text
    'a'
    ```

اما راه ساده‌تری هم وجود دارد!

### اندیس‌های منفی (Negative Index)

در Python می‌توانیم از اندیس منفی برای دسترسی به کاراکترها از انتهای رشته استفاده کنیم.

برای انتخاب آخرین کاراکتر کافی است از اندیس `-1` استفاده کنیم:

!!! example "Python"

    ```python
    fruit[-1]
    ```

    **Output:**

    ```text
    'a'
    ```

اندیس‌های منفی از انتهای رشته به سمت ابتدا حرکت می‌کنند:

- `-1`: آخرین کاراکتر
    
- `-2`: کاراکتر یکی مانده به آخر
    
- `-3`: سومین کاراکتر از انتها
    

و به همین ترتیب ادامه پیدا می‌کند.

پس اگر بخواهیم آخرین حرف یک رشته را به دست بیاوریم، دیگر نیازی نیست طول آن را محاسبه کنیم و یک واحد از آن کم کنیم؛ استفاده از `-1` کافی است.
