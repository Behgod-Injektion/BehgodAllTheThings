## عبارت‌های منظم (Regular Expressions)

تا اینجا دیدیم که اگر دقیقاً بدانیم دنبال چه دنباله‌ای از کاراکترها هستیم، می‌توانیم از عملگر `in` برای پیدا کردن آن و از متد `replace()` برای جایگزین‌کردنش استفاده کنیم.

اما ابزاری قدرتمندتر هم وجود دارد که علاوه بر این کارها، امکانات بسیار بیشتری در اختیارمان قرار می‌دهد: **Regular Expressions** یا به‌اختصار **Regex**.

عبارت منظم به ما اجازه می‌دهد به‌جای جست‌وجوی یک رشته دقیق، الگویی تعریف کنیم و متن را بر اساس آن الگو جست‌وجو کنیم.

برای اینکه با این مفهوم آشنا شویم، از یک مثال ساده شروع می‌کنیم و به‌تدریج قابلیت‌های بیشتری را بررسی خواهیم کرد.

فرض کن دوباره می‌خواهیم تمام خطوطی را پیدا کنیم که شامل یک کلمه مشخص هستند. این بار می‌خواهیم به دنبال نام شخصیت اصلی رمان، یعنی Count Dracula، بگردیم.

ابتدا یک رشته نمونه داریم:

!!! example "Python"

    ```python
    text = "I am Dracula; and I bid you welcome, Mr. Harker, to my house."
    ```

و الگویی که می‌خواهیم جست‌وجو کنیم:

!!! example "Python"

    ```python
    pattern = 'Dracula'
    ```

### ماژول re و تابع search()

در Python، ماژولی به نام `re` وجود دارد که توابع موردنیاز برای کار با عبارت‌های منظم را فراهم می‌کند.

برای استفاده از آن، ابتدا ماژول را وارد می‌کنیم:

!!! example "Python"

    ```python
    import re
    ```

حالا می‌توانیم از تابع `search()` برای جست‌وجوی الگو در متن استفاده کنیم:

!!! example "Python"

    ```python
    result = re.search(pattern, text)
    result
    ```

    **Output:**

    ```text
    <re.Match object; span=(5, 12), match='Dracula'>
    ```

اگر الگوی موردنظر در متن پیدا شود، تابع `search()` یک شیء از نوع `Match` برمی‌گرداند.

این شیء اطلاعات مختلفی درباره نتیجه جست‌وجو در اختیارمان قرار می‌دهد.

برای مثال، یکی از ویژگی‌های آن `string` است که متن اصلیِ مورد جست‌وجو را نگه می‌دارد:

!!! example "Python"

    ```python
    result.string
    ```

    **Output:**

    ```text
    'I am Dracula; and I bid you welcome, Mr. Harker, to my house.'
    ```

همچنین متد `group()` بخشی از متن را که با الگوی ما مطابقت داشته است، برمی‌گرداند:

!!! example "Python"

    ```python
    result.group()
    ```

    **Output:**

    ```text
    'Dracula'
    ```

متد دیگری به نام `span()` نیز وجود دارد که موقعیت شروع و پایان بخش تطبیق‌یافته را در رشته مشخص می‌کند:

!!! example "Python"

    ```python
    result.span()
    ```

    **Output:**

    ```text
    (5, 12)
    ```

یعنی تطبیق از اندیس `5` شروع شده و تا اندیس `12` ادامه دارد؛ البته همان‌طور که در برش رشته‌ها دیدیم، اندیس پایان در محدوده نتیجه قرار نمی‌گیرد.

پس عبارت `Dracula` در موقعیت‌های `5` تا `11` رشته قرار دارد.

### وقتی الگویی پیدا نمی‌شود

اگر الگوی موردنظر در متن وجود نداشته باشد، تابع `search()` مقدار `None` را برمی‌گرداند.

برای مثال:

!!! example "Python"

    ```python
    result = re.search('Count', text)
    print(result)
    ```

    **Output:**

    ```text
    None
    ```

بنابراین می‌توانیم با بررسی اینکه نتیجه برابر با `None` هست یا نه، متوجه شویم جست‌وجو موفق بوده است یا خیر:

!!! example "Python"

    ```python
    result == None
    ```

    **Output:**

    ```text
    True
    ```

حالا که با رفتار `search()` و نتیجه‌ای که برمی‌گرداند آشنا شدیم، می‌توانیم این قابلیت را داخل یک تابع قرار دهیم.

### پیدا کردن اولین تطبیق

تابع زیر تمام خطوط فایل کتاب را یکی‌یکی بررسی می‌کند تا اولین خطی را پیدا کند که با الگوی موردنظر مطابقت دارد:

!!! example "Python"

    ```python
    def find_first(pattern):
        for line in open('pg345_cleaned.txt'):
            result = re.search(pattern, line)
            if result != None:
                return result
    ```

به محض اینکه یک تطبیق پیدا شود، تابع همان شیء `Match` را برمی‌گرداند و اجرای تابع تمام می‌شود.

برای مثال، می‌توانیم اولین اشاره به نام `Harker` را در کتاب پیدا کنیم:

!!! example "Python"

    ```python
    result = find_first('Harker')
    result.string
    ```

    **Output:**

    ```text
    'CHAPTER I. Jonathan Harker’s Journal\n'
    ```

در این مثال، استفاده از Regular Expression ضرورت خاصی نداشت؛ چون می‌توانستیم همین کار را ساده‌تر با عملگر `in` انجام دهیم.

اما قدرت واقعی عبارت‌های منظم زمانی مشخص می‌شود که بخواهیم الگوهایی پیچیده‌تر از یک رشته ثابت تعریف کنیم.

## عملگر OR در عبارت‌های منظم

یکی از قابلیت‌های Regex استفاده از کاراکتر ویژه `|` است.

این کاراکتر به ما اجازه می‌دهد چند الگوی جایگزین تعریف کنیم؛ یعنی اگر یکی از الگوهای سمت چپ یا سمت راست آن مطابقت داشته باشد، جست‌وجو موفق خواهد بود.

برای مثال، فرض کن می‌خواهیم اولین اشاره به شخصیت Mina Murray را در کتاب پیدا کنیم؛ اما نمی‌دانیم در متن از نام کوچک او، یعنی `Mina`، استفاده شده یا نام خانوادگی‌اش، یعنی `Murray`.

می‌توانیم هر دو حالت را در یک الگو قرار دهیم:

!!! example "Python"

    ```python
    pattern = r'Mina|Murray'
    result = find_first(pattern)
    result.string
    ```

    **Output:**

    ```text
    'CHAPTER V. Letters—Lucy and Mina\n'
    ```

الگوی `Mina|Murray` به این معناست:

- عبارت `Mina` را پیدا کن.
    
- یا عبارت `Murray` را پیدا کن.
    

در نتیجه، اگر هرکدام از این دو نام در یک خط وجود داشته باشد، آن خط با الگوی ما مطابقت خواهد داشت.

احتمالاً متوجه پیشوند `r` قبل از رشته شده‌ای. این پیشوند نشان‌دهنده یک **Raw String** است؛ یعنی Python بک‌اسلش (`\`) را به‌عنوان آغاز توالی‌های Escape معمول رشته‌ها تفسیر نمی‌کند.

استفاده از Raw String هنگام نوشتن Regex بسیار رایج است، چون در عبارت‌های منظم از بک‌اسلش برای تعریف بسیاری از الگوهای ویژه استفاده می‌کنیم.

### شمارش تعداد تطبیق‌ها

حالا می‌توانیم از همین قابلیت برای شمارش تعداد خطوطی استفاده کنیم که شامل یکی از چند الگوی مشخص هستند.

تابع زیر تمام خطوط کتاب را بررسی می‌کند و تعداد خطوطی را که با الگوی موردنظر مطابقت دارند، برمی‌گرداند:

!!! example "Python"

    ```python
    def count_matches(pattern):
        count = 0

        for line in open('pg345_cleaned.txt'):
            result = re.search(pattern, line)

            if result != None:
                count += 1

        return count
    ```

حالا می‌توانیم تعداد خطوطی را که شامل نام `Mina` یا `Murray` هستند، محاسبه کنیم:

!!! example "Python"

    ```python
    count_matches('Mina|Murray')
    ```

    **Output:**

    ```text
    229
    ```

بنابراین ۲۲۹ خط از کتاب با این الگو مطابقت دارند.

دقت کن که این تابع تعداد خطوط دارای تطبیق را می‌شمارد، نه تعداد کل دفعاتی که این نام‌ها در کتاب ظاهر شده‌اند. اگر یک خط چند بار شامل این نام‌ها باشد، باز هم فقط یک واحد به شمارنده اضافه می‌شود.

## جست‌وجو در ابتدا و انتهای رشته

تا اینجا از Regex برای پیدا کردن الگوهایی استفاده کردیم که ممکن بود در هر نقطه‌ای از یک خط ظاهر شوند.

اما گاهی محل قرارگیری الگو هم اهمیت دارد. مثلاً شاید بخواهیم فقط خطوطی را پیدا کنیم که با یک عبارت مشخص شروع می‌شوند یا به عبارت مشخصی ختم می‌شوند.

برای این کار دو کاراکتر ویژه بسیار کاربردی داریم: `^` و `$`.

### کاراکتر ^ برای ابتدای رشته

کاراکتر `^` ابتدای رشته را مشخص می‌کند.

اگر این کاراکتر را قبل از یک الگو قرار دهیم، فقط رشته‌هایی با آن الگو مطابقت خواهند داشت که از همان عبارت شروع شده باشند.

برای مثال، می‌خواهیم اولین خطی را پیدا کنیم که با کلمه `Dracula` شروع می‌شود:

!!! example "Python"

    ```python
    result = find_first('^Dracula')
    result.string
    ```

    **Output:**

    ```text
    'Dracula, jumping to his feet, said:--\n'
    ```

دقت کن که این الگو فقط به دنبال وجود کلمه `Dracula` در خط نیست؛ بلکه بررسی می‌کند آیا خط دقیقاً با این کلمه شروع شده است یا خیر.

### کاراکتر $ برای انتهای رشته

کاراکتر `$` انتهای رشته را مشخص می‌کند.

اگر آن را بعد از یک الگو قرار دهیم، فقط رشته‌هایی با آن الگو مطابقت خواهند داشت که به عبارت موردنظر ختم شوند.

برای مثال:

!!! example "Python"

    ```python
    result = find_first('Harker$')
    result.string
    ```

    **Output:**

    ```text
    "by five o'clock, we must start off; for it won't do to leave Mrs. Harker\n"
    ```

در این مثال، الگوی `Harker$` به دنبال خطی می‌گردد که به `Harker` ختم شود.

اما یک نکته وجود دارد: خطوط فایل معمولاً در انتهای خود کاراکتر خط جدید (`\n`) دارند. با این حال، در Regex، کاراکتر `$` می‌تواند درست پیش از خط جدید انتهایی نیز مطابقت پیدا کند؛ بنابراین وجود `\n` مانع پیدا شدن این خط نمی‌شود.

پس تا اینجا سه قابلیت مهم Regex را یاد گرفتیم:

- `|` برای تعریف چند الگوی جایگزین (OR).
    
- `^` برای محدودکردن تطبیق به ابتدای رشته.
    
- `$` برای محدودکردن تطبیق به انتهای رشته.
    

این‌ها فقط بخشی از امکانات عبارت‌های منظم هستند. با ترکیب همین قابلیت‌های ساده می‌توانیم جست‌وجوهای بسیار دقیق‌تری انجام دهیم.
