  

## برش لیست (List Slices)

در بخش رشته‌ها با عملگر برش یا همان `Slice` آشنا شدیم. این عملگر برای لیست‌ها هم دقیقاً به همان شکل کار می‌کند.

فرض کن لیستی از چهار حرف داریم:

!!! example "Python"

    ```python
    letters = ['a', 'b', 'c', 'd']
    letters[1:3]
    ```

    **Output:**

    ```text
    ['b', 'c']
    ```

همان‌طور که می‌بینی، عناصر دارای اندیس ۱ و ۲ انتخاب شده‌اند. یادت باشد که اندیس شروع در برش در نظر گرفته می‌شود، اما اندیس پایان شامل نمی‌شود.

اگر اندیس شروع را مشخص نکنیم، برش از ابتدای لیست آغاز می‌شود:

!!! example "Python"

    ```python
    letters[:2]
    ```

    **Output:**

    ```text
    ['a', 'b']
    ```

اگر اندیس پایان را مشخص نکنیم، برش تا انتهای لیست ادامه پیدا می‌کند:

!!! example "Python"

    ```python
    letters[2:]
    ```

    **Output:**

    ```text
    ['c', 'd']
    ```

حالا اگر هر دو اندیس را حذف کنیم چه اتفاقی می‌افتد؟

در این حالت، یک کپی از تمام عناصر لیست به دست می‌آوریم:

!!! example "Python"

    ```python
    letters[:]
    ```

    **Output:**

    ```text
    ['a', 'b', 'c', 'd']
    ```

راه دیگری هم برای کپی کردن یک لیست وجود دارد: استفاده از تابع داخلی `list()`.

!!! example "Python"

    ```python
    list(letters)
    ```

    **Output:**

    ```text
    ['a', 'b', 'c', 'd']
    ```

یک نکتهٔ کوچک اما مهم: چون `list` نام یک تابع داخلی Python است، بهتر است از آن به‌عنوان نام متغیر استفاده نکنی؛ چون با این کار دسترسی به تابع اصلی را تحت تأثیر قرار می‌دهی.

## عملیات روی لیست‌ها (List Operations)

در Python می‌توانیم از بعضی عملگرها برای انجام عملیات روی لیست‌ها استفاده کنیم.

مثلاً عملگر `+` دو لیست را به یکدیگر متصل می‌کند:

!!! example "Python"

    ```python
    t1 = [1, 2]
    t2 = [3, 4]
    t1 + t2
    ```

    **Output:**

    ```text
    [1, 2, 3, 4]
    ```

به این عملیات **الحاق (Concatenation)** می‌گوییم.

عملگر `*` هم می‌تواند یک لیست را به تعداد مشخصی تکرار کند:

!!! example "Python"

    ```python
    ['spam'] * 4
    ```

    **Output:**

    ```text
    ['spam', 'spam', 'spam', 'spam']
    ```

البته قرار نیست همهٔ عملگرهای ریاضی روی لیست‌ها کار کنند. مثلاً نمی‌توانیم دو لیست را با `-` از هم کم کنیم یا با `/` تقسیم کنیم.

اما چند تابع داخلی مفید برای انجام محاسبات روی عناصر لیست وجود دارد.

تابع `sum()` مجموع عناصر یک لیست عددی را محاسبه می‌کند:

!!! example "Python"

    ```python
    sum(t1)
    ```

    **Output:**

    ```text
    3
    ```

تابع `min()` کوچک‌ترین عنصر و تابع `max()` بزرگ‌ترین عنصر را برمی‌گرداند:

!!! example "Python"

    ```python
    min(t1)
    ```

    **Output:**

    ```text
    1
    ```

!!! example "Python"

    ```python
    max(t2)
    ```

    **Output:**

    ```text
    4
    ```

## متدهای لیست (List Methods)

Python متدهای مختلفی برای کار با لیست‌ها در اختیارمان قرار می‌دهد. این متدها عملیات مشخصی را روی خود لیست انجام می‌دهند.

یکی از متدهای پرکاربرد، `append()` است.

این متد یک عنصر جدید را به انتهای لیست اضافه می‌کند:

!!! example "Python"

    ```python
    letters.append('e')
    letters
    ```

    **Output:**

    ```text
    ['a', 'b', 'c', 'd', 'e']
    ```

همان‌طور که می‌بینی، حرف `'e'` به انتهای لیست اضافه شد.

متد دیگری به نام `extend()` وجود دارد که یک لیست را به‌عنوان آرگومان دریافت می‌کند و تمام عناصر آن را به انتهای لیست فعلی اضافه می‌کند:

!!! example "Python"

    ```python
    letters.extend(['f', 'g'])
    letters
    ```

    **Output:**

    ```text
    ['a', 'b', 'c', 'd', 'e', 'f', 'g']
    ```

دقت کن که `extend()` عناصر لیست ورودی را یکی‌یکی اضافه می‌کند، نه اینکه کل لیست ورودی را به‌عنوان یک عنصر جدید درون لیست قرار دهد.

حالا فرض کن بخواهیم یک عنصر را از لیست حذف کنیم. برای این کار دو متد مهم داریم: `pop()` و `remove()`.

### حذف عنصر با استفاده از اندیس: `pop()`

اگر اندیس عنصری را که می‌خواهیم حذف کنیم بدانیم، می‌توانیم از متد `pop()` استفاده کنیم:

!!! example "Python"

    ```python
    t = ['a', 'b', 'c']
    t.pop(1)
    ```

    **Output:**

    ```text
    'b'
    ```

متد `pop()` عنصر موردنظر را از لیست حذف می‌کند و همان عنصر حذف‌شده را هم به‌عنوان مقدار بازگشتی برمی‌گرداند.

برای اطمینان از اینکه لیست واقعاً تغییر کرده، می‌توانیم دوباره مقدار آن را بررسی کنیم:

!!! example "Python"

    ```python
    t
    ```

    **Output:**

    ```text
    ['a', 'c']
    ```

همان‌طور که می‌بینی، عنصر `'b'` حذف شده است.

### حذف عنصر با استفاده از مقدار: `remove()`

اما اگر مقدار عنصری را که می‌خواهیم حذف کنیم بدانیم، ولی اندیس آن را ندانیم، چه؟

در این شرایط می‌توانیم از متد `remove()` استفاده کنیم:

!!! example "Python"

    ```python
    t = ['a', 'b', 'c']
    t.remove('b')
    ```

این متد اولین عنصری را که با مقدار داده‌شده برابر باشد پیدا می‌کند و از لیست حذف می‌کند.

تفاوت مهم `remove()` با `pop()` این است که `remove()` مقدار حذف‌شده را برنمی‌گرداند؛ مقدار بازگشتی آن `None` است.

اما می‌توانیم بررسی کنیم که لیست تغییر کرده است:

!!! example "Python"

    ```python
    t
    ```

    **Output:**

    ```text
    ['a', 'c']
    ```

یک نکتهٔ دیگر هم وجود دارد. اگر مقداری را برای حذف کردن مشخص کنیم که اصلاً در لیست وجود نداشته باشد، Python چه واکنشی نشان می‌دهد؟

مثلاً:

!!! example "Python"

    ```python
    t.remove('d')
    ```

    **Output:**

    ```text
    ValueError: list.remove(x): x not in list
    ```

در این حالت Python یک خطای `ValueError` ایجاد می‌کند؛ چون مقدار `'d'` در لیست وجود ندارد و چیزی برای حذف کردن پیدا نمی‌شود.

پس تفاوت این دو متد را به خاطر بسپار:

|متد|نحوهٔ انتخاب عنصر|مقدار بازگشتی|
|---|---|---|
|`pop(index)`|بر اساس اندیس|عنصر حذف‌شده|
|`remove(value)`|بر اساس مقدار|`None`|

هر دو متد خود لیست را تغییر می‌دهند، اما روش انتخاب عنصر و مقدار بازگشتی آن‌ها متفاوت است.
