# 03 - Lists

در این فصل با یکی از کاربردی‌ترین انواع داده در Python آشنا می‌شویم: **لیست‌ها (Lists)**.

لیست‌ها به ما اجازه می‌دهند چند مقدار را در یک مجموعه نگه‌داری کنیم و به‌راحتی به آن‌ها دسترسی داشته باشیم، تغییرشان دهیم یا روی آن‌ها عملیات مختلفی انجام دهیم.

همچنین در ادامه با مفهوم اشیا (Objects) و اتفاقاتی که ممکن است وقتی چند متغیر به یک شیء مشترک اشاره می‌کنند رخ دهد، بیشتر آشنا خواهیم شد.

در تمرین‌های این فصل نیز قرار است یک فهرست از کلمات بسازیم و از آن برای پیدا کردن کلمات خاصی مثل Palindrome و Anagram استفاده کنیم.

## لیست یک دنباله از مقادیر است (A List Is a Sequence)

قبلاً دیدیم که رشته‌ها (Strings) دنباله‌ای از کاراکترها هستند. لیست‌ها هم ساختار مشابهی دارند؛ با این تفاوت که به‌جای کاراکتر، می‌توانند مقادیر مختلفی را در خود نگه‌داری کنند.

در یک لیست، هر مقدار را یک **عنصر (Element)** می‌نامیم.

ساده‌ترین روش ساخت یک لیست، قرار دادن عناصر آن داخل براکت‌های مربعی `[]` است.

برای مثال، فرض کن بخواهیم دو عدد صحیح را در یک لیست قرار دهیم:

!!! example "Python"

    ```python
    numbers = [42, 123]
    ```

یا شاید بخواهیم فهرستی از نام چند نوع پنیر داشته باشیم:

!!! example "Python"

    ```python
    cheeses = ['Cheddar', 'Edam', 'Gouda']
    ```

تا اینجا ساده بود. اما یک نکته جالب وجود دارد: برخلاف بعضی ساختارهای داده، عناصر یک لیست مجبور نیستند از یک نوع داده باشند.

یعنی می‌توانیم انواع مختلف داده را در یک لیست کنار هم قرار دهیم:

!!! example "Python"

    ```python
    t = ['spam', 2.0, 5, [10, 20]]
    ```

در این مثال، لیست `t` شامل موارد زیر است:

- یک رشته (`str`)
    
- یک عدد اعشاری (`float`)
    
- یک عدد صحیح (`int`)
    
- یک لیست دیگر
    

بله، حتی می‌توانیم یک لیست را داخل لیست دیگری قرار دهیم! به چنین ساختاری **لیست تو‌در‌تو (Nested List)** می‌گوییم.

### لیست خالی (Empty List)

گاهی لازم است یک لیست بسازیم، اما هنوز هیچ عنصری برای قرار دادن داخل آن نداریم.

در این شرایط می‌توانیم یک لیست خالی ایجاد کنیم. برای این کار کافی است از دو براکت مربعی بدون هیچ عنصری درون آن‌ها استفاده کنیم:

!!! example "Python"

    ```python
    empty = []
    ```

برای بررسی تعداد عناصر یک لیست، از تابع `len()` استفاده می‌کنیم.

مثلاً:

!!! example "Python"

    ```python
    cheeses = ['Cheddar', 'Edam', 'Gouda']
    len(cheeses)
    ```

    **Output:**

    ```text
    3
    ```

همان‌طور که انتظار داریم، طول این لیست برابر با ۳ است؛ چون سه عنصر دارد.

طول یک لیست خالی هم برابر با صفر خواهد بود:

!!! example "Python"

    ```python
    empty = []
    len(empty)
    ```

    **Output:**

    ```text
    0
    ```

### نمایش لیست در حافظه

برای درک بهتر نحوه نمایش لیست‌ها، می‌توانیم از یک State Diagram یا نمودار وضعیت استفاده کنیم.

در چنین نموداری، لیست‌ها با جعبه‌هایی نمایش داده می‌شوند که برچسب `list` دارند و عناصر آن‌ها با شماره اندیس درون جعبه قرار می‌گیرند.

نکته مهم این است که لیست خودش یک شیء مستقل است و عناصر آن در موقعیت‌های مشخصی داخل این ساختار قرار دارند. در ادامه، وقتی درباره ارجاع چند متغیر به یک شیء صحبت کنیم، این موضوع اهمیت بیشتری پیدا می‌کند.

## لیست‌ها تغییرپذیر هستند (Lists Are Mutable)

برای دسترسی به یک عنصر از لیست، درست مثل رشته‌ها از عملگر `[]` و اندیس استفاده می‌کنیم.

اندیس اولین عنصر همیشه از صفر شروع می‌شود:

!!! example "Python"

    ```python
    cheeses = ['Cheddar', 'Edam', 'Gouda']
    cheeses[0]
    ```

    **Output:**

    ```text
    'Cheddar'
    ```

اما اینجا یک تفاوت بسیار مهم بین لیست‌ها و رشته‌ها وجود دارد.

یادت هست که رشته‌ها تغییرناپذیر (Immutable) بودند؟ یعنی نمی‌توانستیم کاراکترهای یک رشته موجود را مستقیماً تغییر دهیم.

اما لیست‌ها **تغییرپذیر (Mutable)** هستند. یعنی می‌توانیم پس از ساخت لیست، عناصر آن را تغییر دهیم.

برای مثال، فرض کن بخواهیم عنصر دوم لیست `numbers` را از `123` به `17` تغییر دهیم:

!!! example "Python"

    ```python
    numbers = [42, 123]
    numbers[1] = 17
    numbers
    ```

    **Output:**

    ```text
    [42, 17]
    ```

همان‌طور که می‌بینی، مقدار عنصر دوم که قبلاً `123` بود، حالا به `17` تغییر کرده است.

در اینجا عبارت `numbers[1]` در سمت چپ عملگر انتساب (`=`) قرار گرفته است. این یعنی می‌خواهیم مقدار عنصر موجود در اندیس `1` را تغییر دهیم.

پس تفاوت اصلی را به خاطر بسپار:

- **String:** تغییرناپذیر است؛ نمی‌توانیم کاراکترهای آن را مستقیماً تغییر دهیم.
    
- **List:** تغییرپذیر است؛ می‌توانیم عناصر آن را پس از ساخت تغییر دهیم.
    

### قوانین اندیس‌گذاری در لیست‌ها

قوانین اندیس‌گذاری در لیست‌ها تقریباً همان قوانینی هستند که برای رشته‌ها یاد گرفتیم:

1. می‌توانیم از هر عبارت صحیح (Integer Expression) به‌عنوان اندیس استفاده کنیم.
    
2. اگر بخواهیم عنصری را بخوانیم یا تغییر دهیم که در آن اندیس وجود ندارد، با خطای `IndexError` مواجه می‌شویم.
    
3. اگر اندیس منفی باشد، شمارش از انتهای لیست آغاز می‌شود.
    

برای مثال:

!!! example "Python"

    ```python
    numbers = [42, 17]

    numbers[-1]
    ```

    **Output:**

    ```text
    17
    ```

اندیس `-1` به آخرین عنصر لیست اشاره می‌کند؛ درست مثل رشته‌ها.

### استفاده از in در لیست‌ها

عملگر `in` که قبلاً برای بررسی وجود یک عبارت در رشته‌ها استفاده کردیم، در لیست‌ها هم کاربرد دارد.

با این تفاوت که در اینجا بررسی می‌کند آیا یک عنصر مشخص در لیست وجود دارد یا خیر.

مثلاً:

!!! example "Python"

    ```python
    cheeses = ['Cheddar', 'Edam', 'Gouda']

    'Edam' in cheeses
    ```

    **Output:**

    ```text
    True
    ```

چون `Edam` یکی از عناصر لیست است.

اما اگر عنصری را بررسی کنیم که در لیست وجود ندارد، نتیجه `False` خواهد بود:

!!! example "Python"

    ```python
    'Wensleydale' in cheeses
    ```

    **Output:**

    ```text
    False
    ```

### شمارش عناصر در لیست‌های تو‌در‌تو

حالا برگردیم به مثالی که قبلاً داشتیم:

!!! example "Python"

    ```python
    t = ['spam', 2.0, 5, [10, 20]]
    ```

به نظرت طول این لیست چند است؟

شاید با دیدن تمام مقادیر داخل آن، فکر کنی پنج عنصر دارد؛ اما این‌طور نیست.

برای محاسبه تعداد عناصر مستقیم لیست، از `len()` استفاده می‌کنیم:

!!! example "Python"

    ```python
    len(t)
    ```

    **Output:**

    ```text
    4
    ```

چرا چهار؟

چون لیست داخلی `[10, 20]` خودش فقط **یک عنصر** از لیست بیرونی `t` محسوب می‌شود.

به عبارت دیگر، ساختار لیست ما این چهار عنصر را دارد:

|اندیس|عنصر|
|---|---|
|`0`|`'spam'`|
|`1`|`2.0`|
|`2`|`5`|
|`3`|`[10, 20]`|

دو عدد `10` و `20` داخل لیست داخلی قرار دارند، نه مستقیماً داخل لیست `t`.

به همین دلیل، اگر بررسی کنیم که آیا `10` یکی از عناصر مستقیم `t` است یا نه، نتیجه `False` خواهد بود:

!!! example "Python"

    ```python
    10 in t
    ```

    **Output:**

    ```text
    False
    ```

این رفتار کاملاً منطقی است؛ چون عملگر `in` فقط عناصر مستقیم همان لیست را بررسی می‌کند و برای جست‌وجو در لیست‌های تو‌در‌تو به‌صورت خودکار وارد آن‌ها نمی‌شود.

پس اگر بخواهیم وجود `10` را در لیست داخلی بررسی کنیم، باید ابتدا به آن لیست دسترسی پیدا کنیم:

!!! example "Python"

    ```python
    10 in t[3]
    ```

    **Output:**

    ```text
    True
    ```

اینجا `t[3]` همان لیست داخلی `[10, 20]` است؛ بنابراین `10` در آن وجود دارد.
