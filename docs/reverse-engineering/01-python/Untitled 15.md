## برش رشته‌ها (String Slices)

تا اینجا یاد گرفتیم چطور با استفاده از اندیس، به یک کاراکتر مشخص از رشته دسترسی پیدا کنیم. اما گاهی به‌جای یک کاراکتر، به بخشی از رشته نیاز داریم. به این بخش از یک رشته **Slice** یا برش می‌گوییم.

برای انتخاب یک برش، از عملگر `[]` استفاده می‌کنیم؛ با این تفاوت که به‌جای یک اندیس، دو اندیس را با `:` از هم جدا می‌کنیم:

!!! example "Python"

````
```python
fruit = 'banana'
fruit[0:3]
```

**Output:**

```text
'ban'
```
````

ساختار کلی به این شکل است:

```
string[start:end]
```

این عبارت بخشی از رشته را از اندیس `start` تا اندیس `end` انتخاب می‌کند؛ با یک تفاوت مهم:

- کاراکتر موجود در اندیس شروع (`start`) در برش قرار می‌گیرد.
    
- کاراکتر موجود در اندیس پایان (`end`) در برش قرار نمی‌گیرد.
    

به عبارت دیگر، اندیس شروع شامل می‌شود، اما اندیس پایان نه.

شاید در نگاه اول این رفتار کمی عجیب به نظر برسد. برای درک بهتر، تصور کن اندیس‌ها به‌جای اینکه روی کاراکترها قرار بگیرند، بین آن‌ها قرار دارند. در این حالت، برش `fruit[0:3]` دقیقاً سه کاراکتر اول را انتخاب می‌کند.

برای مثال:

```
fruit = 'banana'
fruit[3:6]
```

خروجی:

```
'ana'
```

دقت کن که اندیس `6` برای یک کاراکتر مستقل معتبر نیست؛ چون آخرین کاراکتر رشته در اندیس `5` قرار دارد. اما در برش رشته‌ها، استفاده از `6` کاملاً مجاز است؛ چون اندیس پایان مشخص می‌کند برش تا کجا ادامه پیدا کند، نه اینکه حتماً به کاراکتری در آن موقعیت دسترسی پیدا کنیم.

### حذف یکی از اندیس‌ها

در برش رشته‌ها، لازم نیست همیشه هر دو اندیس را مشخص کنیم.

اگر اندیس شروع را ننویسیم، برش از ابتدای رشته آغاز می‌شود:

```
fruit = 'banana'
fruit[:3]
```

خروجی:

```
'ban'
```

اگر اندیس پایان را حذف کنیم، برش تا انتهای رشته ادامه پیدا می‌کند:

```
fruit = 'banana'
fruit[3:]
```

خروجی:

```
'ana'
```

حالا یک حالت دیگر را بررسی کنیم. اگر اندیس شروع و پایان برابر باشند، چه اتفاقی می‌افتد؟

```
fruit = 'banana'
fruit[3:3]
```

خروجی:

```
''
```

نتیجه یک رشته خالی (Empty String) است. رشته خالی هیچ کاراکتری ندارد و طول آن برابر با صفر است:

```
len('')
```

خروجی:

```
0
```

حالا یک سؤال: اگر هر دو اندیس را حذف کنیم و بنویسیم `fruit[:]`، چه اتفاقی می‌افتد؟

این عبارت کل رشته را از ابتدا تا انتها انتخاب می‌کند:

```
fruit = 'banana'
fruit[:]
```

خروجی:

```
'banana'
```

## تغییرناپذیری رشته‌ها (Strings Are Immutable)

فرض کن رشته‌ای به نام `greeting` داریم و می‌خواهیم اولین کاراکتر آن را تغییر دهیم. شاید در نگاه اول فکر کنیم می‌توانیم مثل لیست‌ها، با استفاده از اندیس مستقیماً مقدار یک کاراکتر را تغییر دهیم:

```
greeting = 'Hello, world!'
greeting[0] = 'J'
```

اما اجرای این کد با خطای زیر مواجه می‌شود:

```
TypeError: 'str' object does not support item assignment
```

این خطا به ما می‌گوید که شیء از نوع `str` اجازه نمی‌دهد مقدار یکی از اعضای آن را مستقیماً تغییر دهیم.

دلیل این رفتار یک ویژگی مهم رشته‌ها در Python است: رشته‌ها **Immutable** یا تغییرناپذیر هستند.

تغییرناپذیری یعنی پس از ساخته‌شدن یک رشته، نمی‌توانیم کاراکترهای همان رشته را تغییر دهیم، حذف کنیم یا با کاراکترهای دیگری جایگزین کنیم.

پس اگر بخواهیم نسخه‌ای متفاوت از یک رشته داشته باشیم، باید یک رشته جدید بسازیم.

برای مثال، می‌خواهیم حرف اول `Hello` را با `J` جایگزین کنیم تا به `Jello` برسیم. می‌توانیم این کار را با ترکیب دو رشته انجام دهیم:

```
greeting = 'Hello, world!'
new_greeting = 'J' + greeting[1:]
new_greeting
```

خروجی:

```
'Jello, world!'
```

بیایید ببینیم این عبارت دقیقاً چه کاری انجام می‌دهد:

1. عبارت `greeting[1:]` تمام کاراکترهای رشته را از اندیس `1` تا انتها انتخاب می‌کند؛ یعنی `ello, world!`.
    
2. سپس با عملگر `+`، کاراکتر `J` را به ابتدای این بخش اضافه می‌کنیم.
    
3. نتیجه در متغیر جدیدی به نام `new_greeting` قرار می‌گیرد.
    

نکته مهم این است که رشته اصلی هیچ تغییری نکرده است:

```
greeting
```

خروجی:

```
'Hello, world!'
```

پس با اینکه مقدار جدیدی ساختیم، مقدار قبلی همچنان دست‌نخورده باقی مانده است.

## مقایسه رشته‌ها (String Comparison)

عملگرهای مقایسه‌ای که قبلاً یاد گرفتیم، روی رشته‌ها هم قابل استفاده هستند.

برای بررسی برابر بودن دو رشته، از عملگر `==` استفاده می‌کنیم:

```
word = 'banana'

if word == 'banana':
    print('All right, banana.')
```

خروجی:

```
All right, banana.
```

اما فقط به بررسی برابری محدود نیستیم. عملگرهای `<`، `>`، `<=` و `>=` نیز می‌توانند برای مقایسه رشته‌ها استفاده شوند.

یکی از کاربردهای این مقایسه‌ها، مرتب‌سازی کلمات به ترتیب الفبایی است.

برای مثال، تابع زیر یک کلمه را با `banana` مقایسه می‌کند:

```
def compare_word(word):
    if word < 'banana':
        print(word, 'comes before banana.')
    elif word > 'banana':
        print(word, 'comes after banana.')
    else:
        print('All right, banana.')
```

حالا تابع را با کلمه `apple` اجرا می‌کنیم:

```
compare_word('apple')
```

خروجی:

```
apple comes before banana.
```

اما یک نکته مهم وجود دارد: مقایسه رشته‌ها در Python دقیقاً مطابق با چیزی که انسان‌ها از ترتیب الفبایی انتظار دارند انجام نمی‌شود.

برای مثال، حروف بزرگ و کوچک در مقایسه رشته‌ها رفتار متفاوتی دارند. در ترتیب مقایسه‌ای Python، حروف بزرگ انگلیسی قبل از حروف کوچک قرار می‌گیرند.

بنابراین:

```
compare_word('Pineapple')
```

خروجی:

```
Pineapple comes before banana.
```

شاید عجیب به نظر برسد! چون از دید ما، کلمه `Pineapple` باید بعد از `banana` قرار بگیرد؛ اما Python در مقایسه مستقیم، به بزرگی و کوچکی حروف هم توجه می‌کند.

برای جلوگیری از این مشکل، می‌توانیم قبل از مقایسه، هر دو رشته را به یک قالب یکسان تبدیل کنیم؛ مثلاً تمام حروف را کوچک کنیم:

```
word = 'Pineapple'

if word.lower() < 'banana':
    print(word, 'comes before banana.')
elif word.lower() > 'banana':
    print(word, 'comes after banana.')
else:
    print('All right, banana.')
```

با استفاده از `lower()`، رشته را به نسخه‌ای با حروف کوچک تبدیل می‌کنیم و سپس مقایسه را انجام می‌دهیم.

این نکته را به خاطر بسپار؛ مخصوصاً زمانی که قرار است رشته‌ها را بر اساس ترتیب الفبایی مرتب یا با یکدیگر مقایسه کنی.

## متدهای رشته (String Methods)

رشته‌ها در Python متدهای مختلفی دارند که برای انجام عملیات متداول روی آن‌ها استفاده می‌شوند.

اما متد (Method) دقیقاً چیست؟

متد از نظر عملکرد شباهت زیادی به تابع دارد: می‌تواند ورودی دریافت کند، عملیاتی انجام دهد و مقداری را برگرداند. تفاوت اصلی آن‌ها در نحوه فراخوانی است.

برای مثال، متدی به نام `upper()` وجود دارد که تمام حروف کوچک یک رشته را به حروف بزرگ تبدیل می‌کند و یک رشته جدید برمی‌گرداند.

فرض کن بخواهیم رشته `banana` را به حروف بزرگ تبدیل کنیم.

ممکن است تصور کنیم باید چیزی شبیه به فراخوانی یک تابع بنویسیم:

```
upper(word)
```

اما متدها با استفاده از نقطه (`.`) فراخوانی می‌شوند:

```
word = 'banana'
new_word = word.upper()
new_word
```

خروجی:

```
'BANANA'
```

در عبارت `word.upper()`:

- `word` رشته‌ای است که می‌خواهیم عملیات روی آن انجام شود.
    
- نقطه (`.`) مشخص می‌کند که قرار است به یکی از متدهای این رشته دسترسی پیدا کنیم.
    
- `upper` نام متدی است که می‌خواهیم فراخوانی کنیم.
    
- پرانتزهای خالی `()` نشان می‌دهند که این متد در این مثال هیچ آرگومانی دریافت نمی‌کند.
    

به اجرای یک متد، **Invocation** یا فراخوانی متد گفته می‌شود.

بنابراین وقتی می‌نویسیم:

```
word.upper()
```

می‌گوییم متد `upper` را روی رشته `word` فراخوانی می‌کنیم.

یادت باشد که `upper()` رشته اصلی را تغییر نمی‌دهد؛ بلکه یک رشته جدید با حروف بزرگ برمی‌گرداند. این رفتار با ویژگی تغییرناپذیری رشته‌ها که کمی قبل یاد گرفتیم، کاملاً سازگار است.
