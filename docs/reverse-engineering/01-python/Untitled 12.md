## Updating Variables؛ به‌روزرسانی متغیرها

همان‌طور که احتمالاً تا الان متوجه شده‌ای، در Python می‌توانیم چندین بار به یک متغیر مقدار جدید اختصاص دهیم.

وقتی دوباره به یک متغیر مقدار می‌دهیم، آن متغیر از این به بعد به مقدار جدید اشاره می‌کند و دیگر به مقدار قبلی اشاره نخواهد کرد.

برای مثال، ابتدا یک متغیر به نام `x` تعریف می‌کنیم:

!!! example "Python"

    ```python
    x = 5
    x
    ```

    **Output:**

    ```text
    5
    ```

حالا می‌توانیم مقدار جدیدی به همان متغیر اختصاص دهیم:

!!! example "Python"

    ```python
    x = 7
    x
    ```

    **Output:**

    ```text
    7
    ```

اگر این دو انتساب را در یک نمودار وضعیت (State Diagram) نمایش دهیم، ابتدا متغیر `x` به مقدار `5` اشاره می‌کند و بعد از انتساب دوم، به مقدار `7` اشاره خواهد کرد.

در چنین نموداری، فلش نقطه‌چین نشان می‌دهد که `x` دیگر به مقدار `5` اشاره نمی‌کند و فلش پیوسته نشان‌دهنده ارتباط جدید آن با مقدار `7` است.

### Update؛ به‌روزرسانی مقدار متغیر

یکی از شکل‌های رایج انتساب، **Update** یا به‌روزرسانی است. در این حالت، مقدار جدید متغیر به مقدار قبلی آن وابسته است.

مثلاً:

!!! example "Python"

    ```python
    x = x + 1
    x
    ```

    **Output:**

    ```text
    8
    ```

این دستور یعنی:

1. مقدار فعلی `x` را بخوان.
    
2. یک واحد به آن اضافه کن.
    
3. نتیجه را دوباره در خود `x` ذخیره کن.
    

پس اگر مقدار فعلی `x` برابر `7` باشد، بعد از اجرای دستور بالا مقدار آن `8` خواهد شد.

اما یک نکته مهم وجود دارد: اگر بخواهیم متغیری را که هنوز وجود ندارد به‌روزرسانی کنیم، با خطا مواجه می‌شویم.

مثلاً:

!!! example "Python"

    ```python
    y = y + 1
    ```

    **Output:**

    ```text
    NameError: name 'y' is not defined
    ```

چرا؟

چون Python ابتدا عبارت سمت راست علامت `=` را ارزیابی می‌کند و بعد نتیجه را به متغیر سمت چپ اختصاص می‌دهد. بنابراین قبل از اینکه بتواند مقدار جدید `y` را محاسبه کند، باید مقدار فعلی آن را بخواند؛ اما چنین متغیری هنوز تعریف نشده است.

پس قبل از به‌روزرسانی یک متغیر، باید ابتدا آن را مقداردهی اولیه (Initialize) کنیم. معمولاً این کار با یک انتساب ساده انجام می‌شود:

!!! example "Python"

    ```python
    y = 0
    y = y + 1
    y
    ```

    **Output:**

    ```text
    1
    ```

به این ترتیب، ابتدا `y` را با مقدار صفر ایجاد کردیم و سپس مقدار آن را یک واحد افزایش دادیم.

به افزایش مقدار یک متغیر **Increment** و به کاهش مقدار آن **Decrement** می‌گوییم.

## Looping and Counting؛ حلقه و شمارش

حالا که با به‌روزرسانی متغیرها آشنا شدیم، می‌توانیم از حلقه‌ها برای شمارش استفاده کنیم.

فرض کن می‌خواهیم تعداد کل کلمات موجود در فایل `words.txt` را محاسبه کنیم.

برای این کار، یک متغیر به نام `total` ایجاد می‌کنیم و مقدار اولیه آن را صفر قرار می‌دهیم:

!!! example "Python"

    ```python
    total = 0

    for line in open('words.txt'):
        word = line.strip()
        total = total + 1
    ```

در ابتدای برنامه، `total` برابر صفر است.

سپس حلقه `for` تمام خطوط فایل را یکی‌یکی می‌خواند. در هر تکرار، یک کلمه استخراج می‌شود و مقدار `total` یک واحد افزایش پیدا می‌کند.

بنابراین وقتی حلقه تمام شود، `total` تعداد کل کلمات فایل را در خود نگه می‌دارد.

!!! example "Python"

    ```python
    total
    ```

    **Output:**

    ```text
    113783
    ```

به متغیری که برای شمارش تعداد دفعات وقوع یک اتفاق استفاده می‌شود، **Counter** یا «شمارنده» می‌گوییم.

### استفاده از چند شمارنده

حالا می‌خواهیم علاوه بر تعداد کل کلمات، تعداد کلماتی را هم بشماریم که شامل حرف `e` هستند.

برای این کار به یک شمارنده دوم به نام `count` نیاز داریم:

!!! example "Python"

    ```python
    total = 0
    count = 0

    for line in open('words.txt'):
        word = line.strip()
        total = total + 1

        if has_e(word):
            count = count + 1
    ```

این برنامه دو کار انجام می‌دهد:

- در هر تکرار، مقدار `total` را یک واحد افزایش می‌دهد؛ چون یک کلمه از فایل خوانده شده است.
    
- اگر تابع `has_e()` تشخیص دهد که کلمه شامل `e` است، مقدار `count` را یک واحد افزایش می‌دهد.
    

پس در پایان، `total` تعداد کل کلمات و `count` تعداد کلماتی را نشان می‌دهد که حداقل یک بار حرف `e` را دارند.

بیایید مقدار `count` را بررسی کنیم:

!!! example "Python"

    ```python
    count
    ```

    **Output:**

    ```text
    76162
    ```

حالا می‌توانیم نسبت کلماتی را که شامل `e` هستند به کل کلمات، به‌صورت درصد محاسبه کنیم:

!!! example "Python"

    ```python
    count / total * 100
    ```

    **Output:**

    ```text
    66.93618554617122
    ```

یعنی تقریباً دو سوم کلمات موجود در این فهرست شامل حرف `e` هستند.

حالا بهتر می‌توانیم درک کنیم که چرا نوشتن یک کتاب بدون استفاده از چنین کلماتی کار بسیار دشواری است!

## The in Operator؛ عملگر in

تابع `has_e()` که در ابتدای فصل نوشتیم، کمی پیچیده‌تر از چیزی است که واقعاً نیاز داریم.

Python عملگری به نام `in` دارد که بررسی می‌کند آیا یک کاراکتر یا زیررشته (Substring) درون یک رشته وجود دارد یا نه.

برای مثال:

!!! example "Python"

    ```python
    word = 'Gadsby'
    'e' in word
    ```

    **Output:**

    ```text
    False
    ```

چون حرف `e` در رشته `Gadsby` وجود ندارد، نتیجه `False` است.

با استفاده از `in` می‌توانیم تابع `has_e()` را ساده‌تر بنویسیم:

!!! example "Python"

    ```python
    def has_e(word):
        if 'E' in word or 'e' in word:
            return True
        else:
            return False
    ```

اما یک نکته وجود دارد: شرط `if` خودش یک مقدار بولی (`True` یا `False`) تولید می‌کند. پس چرا همان مقدار را مستقیماً برنگردانیم؟

در واقع، می‌توانیم کل تابع را به یک خط کاهش دهیم:

!!! example "Python"

    ```python
    def has_e(word):
        return 'E' in word or 'e' in word
    ```

این نسخه دقیقاً همان رفتار نسخه قبلی را دارد، اما ساده‌تر و خواناتر است.

### استفاده از lower

حتی می‌توانیم تابع را از این هم ساده‌تر کنیم!

رشته‌ها در Python متدی به نام `lower()` دارند که تمام حروف بزرگ انگلیسی را به حروف کوچک تبدیل می‌کند.

مثلاً:

!!! example "Python"

    ```python
    word.lower()
    ```

    **Output:**

    ```text
    'gadsby'
    ```

اما یک نکته مهم: متد `lower()` یک رشته جدید ایجاد می‌کند و رشته اصلی را تغییر نمی‌دهد.

برای اینکه این موضوع را ببینیم، مقدار متغیر `word` را دوباره بررسی می‌کنیم:

!!! example "Python"

    ```python
    word
    ```

    **Output:**

    ```text
    'Gadsby'
    ```

همان‌طور که می‌بینی، مقدار اصلی همچنان `Gadsby` است.

حالا می‌توانیم از `lower()` در تابع `has_e()` استفاده کنیم. کافی است ابتدا رشته را به حروف کوچک تبدیل کنیم و بعد فقط وجود `e` را بررسی کنیم:

!!! example "Python"

    ```python
    def has_e(word):
        return 'e' in word.lower()
    ```

به این ترتیب، دیگر نیازی نیست جداگانه حروف بزرگ و کوچک را بررسی کنیم.

حالا تابع را آزمایش کنیم:

!!! example "Python"

    ```python
    has_e('Gadsby')
    ```

    **Output:**

    ```text
    False
    ```

و:

!!! example "Python"

    ```python
    has_e('Emma')
    ```

    **Output:**

    ```text
    True
    ```

به همین سادگی، با ترکیب دو قابلیت `in` و `lower()` توانستیم تابعی کوتاه‌تر و خواناتر بنویسیم که بدون توجه به بزرگ یا کوچک بودن حروف، وجود `e` را در رشته بررسی می‌کند.
