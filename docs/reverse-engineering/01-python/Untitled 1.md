## فراخوانی توابع (Calling Functions)

تا اینجا یاد گرفتیم چطور تابع تعریف کنیم و آن را فراخوانی کنیم. اما یک قابلیت جالب‌تر هم وجود دارد: **می‌توانیم داخل یک تابع، تابع دیگری را فراخوانی کنیم.**

این یعنی لازم نیست تمام دستورهای برنامه را در یک تابع بزرگ بنویسیم. می‌توانیم کارهای مختلف را به توابع کوچک‌تر تقسیم کنیم و بعد این توابع را کنار هم قرار دهیم.

برای درک بهتر، بیایید با چند تابع، بخش‌هایی از ترانهٔ طنزآمیز «The Spam Song» را نمایش دهیم:

```
Spam, Spam, Spam, Spam,
Spam, Spam, Spam, Spam,
Spam, Spam,
(Lovely Spam, Wonderful Spam!)
Spam, Spam,
```

ابتدا تابعی تعریف می‌کنیم که دو پارامتر دریافت می‌کند:

!!! example "Python"

    ```python
    def repeat(word, n):
        print(word * n)
    ```

پارامتر `word` کلمه یا رشته‌ای است که می‌خواهیم تکرار شود و `n` تعداد دفعات تکرار آن را مشخص می‌کند.

حالا می‌توانیم از این تابع برای چاپ خط اول ترانه استفاده کنیم:

!!! example "Python"

    ```python
    spam = 'Spam, '
    repeat(spam, 4)
    ```

    **Output:**

    ```text
    Spam, Spam, Spam, Spam,
    ```

تابع `repeat()` مقدار `spam` را دریافت می‌کند و آن را چهار بار تکرار می‌کند.

حالا فرض کن بخواهیم دو خط اول ترانه را نمایش دهیم. می‌توانیم دوباره `repeat()` را فراخوانی کنیم؛ اما به‌جای اینکه این کار را هر بار مستقیماً انجام دهیم، یک تابع جدید می‌سازیم:

!!! example "Python"

    ```python
    def first_two_lines():
        repeat(spam, 4)
        repeat(spam, 4)
    ```

این تابع خودش دو بار تابع `repeat()` را فراخوانی می‌کند. برای اجرای آن کافی است بنویسیم:

!!! example "Python"

    ```python
    first_two_lines()
    ```

    **Output:**

    ```text
    Spam, Spam, Spam, Spam,
    Spam, Spam, Spam, Spam,
    ```

حالا نوبت سه خط آخر است. برای آن هم تابع جداگانه‌ای تعریف می‌کنیم:

!!! example "Python"

    ```python
    def last_three_lines():
        repeat(spam, 2)
        print('(Lovely Spam, Wonderful Spam!)')
        repeat(spam, 2)
    ```

با فراخوانی این تابع، سه خط موردنظر نمایش داده می‌شوند:

!!! example "Python"

    ```python
    last_three_lines()
    ```

    **Output:**

    ```text
    Spam, Spam,
    (Lovely Spam, Wonderful Spam!)
    Spam, Spam,
    ```

خب، حالا دو بخش ترانه را داریم. می‌توانیم با تعریف یک تابع دیگر، همهٔ آن‌ها را به هم متصل کنیم:

!!! example "Python"

    ```python
    def print_verse():
        first_two_lines()
        last_three_lines()
    ```

این تابع دو تابع قبلی را به ترتیب فراخوانی می‌کند. برای نمایش کل ترانه هم کافی است آن را اجرا کنیم:

!!! example "Python"

    ```python
    print_verse()
    ```

    **Output:**

    ```text
    Spam, Spam, Spam, Spam,
    Spam, Spam, Spam, Spam,
    Spam, Spam,
    (Lovely Spam, Wonderful Spam!)
    Spam, Spam,
    ```

### چند تابع، یک جریان اجرا

بیایید ببینیم هنگام اجرای `print_verse()` چه اتفاقی می‌افتد:

1. تابع `print_verse()` اجرا می‌شود.
    
2. این تابع، `first_two_lines()` را فراخوانی می‌کند.
    
3. تابع `first_two_lines()` دو بار `repeat()` را فراخوانی می‌کند.
    
4. بعد از اتمام آن، اجرای `print_verse()` ادامه پیدا می‌کند و `last_three_lines()` فراخوانی می‌شود.
    
5. این تابع هم `repeat()` و `print()` را اجرا می‌کند.
    

پس در نهایت، زنجیره‌ای از فراخوانی توابع داریم که به اجرای دستورهای `print()` منتهی می‌شود.

البته می‌توانستیم همین خروجی را با تعداد کمتری تابع هم تولید کنیم. هدف این مثال صرفاً چاپ یک ترانه نیست؛ می‌خواهیم ببینیم چطور می‌توانیم یک مسئله را به بخش‌های کوچک‌تر تقسیم کنیم و با کنار هم قرار دادن توابع، برنامه‌ای بزرگ‌تر بسازیم.

## تکرار (Repetition)

تا اینجا اگر بخواهیم یک تابع را چند بار اجرا کنیم، باید چند بار آن را فراخوانی کنیم. اما اگر تعداد دفعات تکرار زیاد باشد چه؟

مثلاً اگر بخواهیم یک ترانه را ده بار نمایش دهیم، آیا واقعاً باید ده بار `print_verse()` را بنویسیم؟ قطعاً راه بهتری وجود دارد!

در Python برای تکرار یک مجموعه دستور از حلقه‌ها (Loops) استفاده می‌کنیم. یکی از این حلقه‌ها، `for` است.

ابتدا یک مثال ساده را بررسی کنیم:

!!! example "Python"

    ```python
    for i in range(2):
        print(i)
    ```

    **Output:**

    ```text
    0
    1
    ```

ساختار این کد را بررسی کنیم.

خط اول، Header حلقه است و با `:` تمام می‌شود. خط دوم، Body حلقه است و به همین دلیل باید تورفتگی داشته باشد.

اما اجزای خط اول چه معنایی دارند؟

```
for i in range(2):
```

- `for` کلمهٔ کلیدی شروع حلقه است.
    
- `i` متغیری است که در هر تکرار، یکی از مقادیر دنباله را دریافت می‌کند.
    
- `in` مشخص می‌کند که مقادیر موردنظر از کجا گرفته می‌شوند.
    
- `range(2)` دنباله‌ای شامل دو مقدار `0` و `1` ایجاد می‌کند.
    

در Python، شمارش معمولاً از صفر شروع می‌شود. بنابراین `range(2)` شامل اعداد `0` و `1` است، نه `1` و `2`.

### حلقهٔ for چگونه اجرا می‌شود؟

وقتی Python به حلقه می‌رسد، مراحل زیر اتفاق می‌افتند:

1. اولین مقدار تولیدشده توسط `range(2)`، یعنی `0`، به متغیر `i` اختصاص داده می‌شود.
    
2. دستور `print(i)` اجرا می‌شود و مقدار `0` را نمایش می‌دهد.
    
3. پس از پایان Body، اجرای حلقه دوباره به مرحلهٔ دریافت مقدار بعدی برمی‌گردد.
    
4. این بار مقدار `1` به `i` اختصاص داده می‌شود و `print(i)` آن را نمایش می‌دهد.
    
5. چون مقدار دیگری باقی نمانده است، حلقه تمام می‌شود.
    

به این ترتیب، دستور داخل Body دو بار اجرا شده است.

به همین دلیل به این ساختار Loop یا حلقه می‌گوییم؛ چون اجرای دستورها تا زمانی ادامه پیدا می‌کند که مقادیر موردنظر باقی مانده باشند.

### استفاده از for برای تکرار یک تابع

حالا که با نحوهٔ کار `for` آشنا شدیم، می‌توانیم از آن برای نمایش دو بیت از ترانه استفاده کنیم:

!!! example "Python"

    ```python
    for i in range(2):
        print("Verse", i)
        print_verse()
        print()
    ```

    **Output:**

    ```text
    Verse 0
    Spam, Spam, Spam, Spam,
    Spam, Spam, Spam, Spam,
    Spam, Spam,
    (Lovely Spam, Wonderful Spam!)
    Spam, Spam,

    Verse 1
    Spam, Spam, Spam, Spam,
    Spam, Spam, Spam, Spam,
    Spam, Spam,
    (Lovely Spam, Wonderful Spam!)
    Spam, Spam,
    ```

در این مثال، حلقه دو بار اجرا می‌شود. در هر تکرار:

- شمارهٔ بیت با `print("Verse", i)` نمایش داده می‌شود.
    
- تابع `print_verse()` تمام بیت را چاپ می‌کند.
    
- دستور `print()` یک خط خالی ایجاد می‌کند تا بیت‌ها از هم جدا شوند.
    

نکتهٔ جالب اینجاست که می‌توانیم یک حلقه را داخل یک تابع هم قرار دهیم.

### قرار دادن حلقه داخل تابع

فرض کن می‌خواهیم تابعی داشته باشیم که تعداد مشخصی از بیت‌های ترانه را نمایش دهد. برای این کار، پارامتری به نام `n` تعریف می‌کنیم تا تعداد دفعات تکرار را مشخص کند:

!!! example "Python"

    ```python
    def print_n_verses(n):
        for i in range(n):
            print_verse()
            print()
    ```

حالا این تابع می‌تواند با دریافت یک عدد صحیح، همان تعداد بیت را نمایش دهد.

برای مثال، اگر `n` برابر با `3` باشد، حلقه سه بار اجرا می‌شود و در هر بار `print_verse()` یک بیت را نمایش می‌دهد.

یک نکتهٔ کوچک هم باقی می‌ماند: در این مثال از متغیر `i` داخل Body استفاده نکرده‌ایم. با این حال، در ساختار `for` همچنان باید متغیری برای دریافت مقادیر دنباله مشخص کنیم. این متغیر در هر تکرار مقدار بعدی را دریافت می‌کند، حتی اگر خودمان از آن استفاده نکنیم.
