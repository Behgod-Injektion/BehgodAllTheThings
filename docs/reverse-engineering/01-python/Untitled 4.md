## عملگرهای منطقی (Logical Operators)

تا اینجا یاد گرفتیم چطور دو مقدار را با عملگرهای رابطه‌ای مقایسه کنیم و نتیجه‌ای از نوع `bool` به دست بیاوریم. اما گاهی لازم است چند شرط را هم‌زمان بررسی کنیم.

برای این کار از عملگرهای منطقی (Logical Operators) استفاده می‌کنیم. سه عملگر منطقی اصلی در Python عبارت‌اند از:

- `and`
    
- `or`
    
- `not`
    

معنای این عملگرها تقریباً مشابه کاربرد آن‌ها در زبان انگلیسی است.

### عملگر and

عملگر `and` زمانی نتیجهٔ `True` می‌دهد که **تمام شرط‌های دو طرف آن درست باشند.**

مثلاً فرض کن می‌خواهیم بررسی کنیم آیا مقدار `x` بزرگ‌تر از صفر و کوچک‌تر از ۱۰ است یا خیر:

!!! example "Python"

    ```python
    x = 5
    x > 0 and x < 10
    ```

    **Output:**

    ```text
    True
    ```

چون هر دو شرط درست هستند، نتیجهٔ کل عبارت `True` می‌شود.

اما اگر حتی یکی از شرط‌ها نادرست باشد، نتیجهٔ `and` برابر `False` خواهد بود.

### عملگر or

عملگر `or` زمانی نتیجهٔ `True` می‌دهد که **حداقل یکی از شرط‌ها درست باشد.** بنابراین اگر هر دو شرط هم درست باشند، باز هم نتیجه `True` است.

برای مثال، می‌خواهیم بررسی کنیم آیا عددی بر ۲ یا ۳ بخش‌پذیر است:

!!! example "Python"

    ```python
    x = 5
    x % 2 == 0 or x % 3 == 0
    ```

    **Output:**

    ```text
    False
    ```

چرا `False`؟

چون ۵ نه بر ۲ بخش‌پذیر است و نه بر ۳. پس هر دو شرط نادرست هستند.

### عملگر not

عملگر `not` نتیجهٔ یک عبارت بولی را معکوس می‌کند:

- اگر نتیجه `True` باشد، آن را به `False` تبدیل می‌کند.
    
- اگر نتیجه `False` باشد، آن را به `True` تبدیل می‌کند.
    

مثلاً:

!!! example "Python"

    ```python
    x = 5
    y = 7

    not x > y
    ```

    **Output:**

    ```text
    True
    ```

ابتدا عبارت `x > y` را بررسی می‌کنیم. چون ۵ بزرگ‌تر از ۷ نیست، نتیجه `False` است. حالا `not` این نتیجه را معکوس می‌کند و در نهایت `True` به دست می‌آید.

### آیا عملگرهای منطقی فقط با bool کار می‌کنند؟

از نظر مفهومی، عملوندهای عملگرهای منطقی باید عبارت‌های بولی باشند؛ اما Python در این زمینه انعطاف بیشتری دارد.

در Python هر شیء می‌تواند در یک زمینهٔ بولی (Boolean Context) به‌عنوان درست یا نادرست ارزیابی شود.

برای مثال، اعداد غیرصفر در این زمینه معادل `True` و عدد صفر معادل `False` در نظر گرفته می‌شود.

!!! example "Python"

    ```python
    42 and True
    ```

    **Output:**

    ```text
    True
    ```

این انعطاف‌پذیری گاهی مفید است، اما ممکن است باعث سردرگمی هم بشود. به همین دلیل بهتر است در ابتدای یادگیری، عملگرهای منطقی را عمدتاً با عبارت‌های بولی استفاده کنیم.

## دستورهای شرطی (if Statements)

تا اینجا یاد گرفتیم چطور شرط‌های مختلف را بررسی کنیم؛ اما هنوز نمی‌توانیم بر اساس نتیجهٔ آن‌ها مسیر اجرای برنامه را تغییر دهیم.

فرض کن می‌خواهیم برنامه‌ای بنویسیم که اگر عددی مثبت بود، پیامی نمایش دهد. اگر عدد منفی بود چه؟ آیا باید همان پیام را نمایش دهیم؟

اینجاست که دستورهای شرطی (Conditional Statements) وارد می‌شوند.

ساده‌ترین دستور شرطی در Python، دستور `if` است.

!!! example "Python"

    ```python
    x = 5

    if x > 0:
        print('x is positive')
    ```

    **Output:**

    ```text
    x is positive
    ```

کلمهٔ `if` یک Keyword در Python است و برای بررسی شرط استفاده می‌شود.

ساختار `if` از دو بخش اصلی تشکیل شده است:

- **Header:** خطی که با `if` شروع می‌شود و شرط را مشخص می‌کند.
    
- **Body:** دستورهایی که در صورت درست بودن شرط اجرا می‌شوند.
    

عبارت بولی بعد از `if` را **Condition** یا شرط می‌نامیم.

در مثال بالا، شرط `x > 0` بررسی می‌شود. چون مقدار `x` برابر ۵ است، شرط درست خواهد بود و دستور داخل Body اجرا می‌شود.

اما اگر شرط نادرست باشد، چه اتفاقی می‌افتد؟

در این حالت، دستورهای داخل Body اجرا نمی‌شوند.

### دستور pass

درون Body یک دستور `if` می‌توانیم هر تعداد دستور قرار دهیم؛ اما یک محدودیت وجود دارد: Body نمی‌تواند کاملاً خالی باشد و باید حداقل یک دستور داشته باشد.

گاهی هنوز نمی‌دانیم قرار است داخل یک بخش چه کدی بنویسیم، اما می‌خواهیم ساختار شرطی را فعلاً ایجاد کنیم. در چنین شرایطی می‌توانیم از دستور `pass` استفاده کنیم.

`pass` هیچ کاری انجام نمی‌دهد و صرفاً به Python می‌گوید که این بخش عمداً خالی گذاشته شده است.

!!! example "Python"

    ```python
    x = -5

    if x < 0:
        pass  # TODO: need to handle negative values!
    ```

در این مثال، شرط برقرار است؛ اما چون تنها دستور داخل Body، یعنی `pass`، هیچ کاری انجام نمی‌دهد، خروجی خاصی مشاهده نمی‌کنیم.

کلمهٔ `TODO` هم یک قرارداد رایج در کامنت‌هاست که به ما یادآوری می‌کند بخشی از کد هنوز باید تکمیل شود.

## بخش else (The else Clause)

تا اینجا فقط زمانی دستور اجرا می‌شد که شرط `if` درست باشد. اما اگر بخواهیم برای حالت نادرست بودن شرط هم دستور مشخصی اجرا کنیم، چه؟

برای این کار از `else` استفاده می‌کنیم.

ساختار آن به شکل زیر است:

!!! example "Python"

    ```python
    if condition:
        # اجرا در صورت درست بودن شرط
    else:
        # اجرا در صورت نادرست بودن شرط
    ```

بیایید با یک مثال واقعی‌تر موضوع را بررسی کنیم. می‌خواهیم مشخص کنیم یک عدد زوج است یا فرد:

!!! example "Python"

    ```python
    x = 5

    if x % 2 == 0:
        print('x is even')
    else:
        print('x is odd')
    ```

    **Output:**

    ```text
    x is odd
    ```

چطور برنامه این موضوع را تشخیص می‌دهد؟

اگر عددی بر ۲ بخش‌پذیر باشد، باقی‌ماندهٔ تقسیم آن بر ۲ برابر صفر خواهد بود. بنابراین شرط `x % 2 == 0` برای اعداد زوج درست است.

اما اگر عدد فرد باشد، باقی‌ماندهٔ تقسیم آن بر ۲ برابر یک خواهد بود. در نتیجه شرط `if` نادرست می‌شود و دستورهای بخش `else` اجرا می‌شوند.

نکتهٔ مهم این است که شرط همیشه یکی از دو حالت `True` یا `False` را دارد. بنابراین در ساختار `if-else` دقیقاً یکی از دو بخش اجرا خواهد شد.

به هر یک از این مسیرهای اجرایی یک **Branch** می‌گوییم.

## شرط‌های زنجیره‌ای (Chained Conditionals)

گاهی مسئله فقط دو حالت ندارد. در چنین شرایطی به تعداد بیشتری Branch نیاز داریم.

مثلاً فرض کن می‌خواهیم دو عدد `x` و `y` را مقایسه کنیم. سه حالت ممکن وجود دارد:

1. `x` کوچک‌تر از `y` باشد.
    
2. `x` بزرگ‌تر از `y` باشد.
    
3. هر دو با یکدیگر برابر باشند.
    

برای چنین شرایطی می‌توانیم از `elif` استفاده کنیم.

`elif` کوتاه‌شدهٔ عبارت `else if` است و امکان بررسی شرط‌های اضافی را فراهم می‌کند.

!!! example "Python"

    ```python
    x = 5
    y = 7

    if x < y:
        print('x is less than y')
    elif x > y:
        print('x is greater than y')
    else:
        print('x and y are equal')
    ```

    **Output:**

    ```text
    x is less than y
    ```

در این مثال، Python شرط‌ها را به‌ترتیب بررسی می‌کند:

1. ابتدا بررسی می‌کند که آیا `x < y` درست است یا خیر.
    
2. اگر شرط اول نادرست باشد، سراغ شرط بعدی یعنی `x > y` می‌رود.
    
3. اگر هیچ‌کدام از شرط‌ها درست نباشند، بخش `else` اجرا می‌شود.
    

در این مثال، شرط اول درست است؛ بنابراین پیام مربوط به آن نمایش داده می‌شود و دیگر شرط‌های بعدی بررسی نمی‌شوند.

### چند نکته دربارهٔ elif

- می‌توانیم به تعداد دلخواه از `elif` استفاده کنیم.
    
- وجود `else` اجباری نیست.
    
- اگر از `else` استفاده کنیم، باید در انتهای ساختار شرطی قرار بگیرد.
    
- شرط‌ها به‌ترتیب بررسی می‌شوند.
    
- به‌محض اینکه یکی از شرط‌ها درست باشد، Branch مربوط به آن اجرا می‌شود و بقیهٔ شرط‌ها نادیده گرفته می‌شوند.
    

نکتهٔ آخر بسیار مهم است: حتی اگر چند شرط هم‌زمان درست باشند، فقط **اولین Branch با شرط درست** اجرا خواهد شد.
