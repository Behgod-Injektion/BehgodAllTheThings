## رشته‌ها (Strings)

تا اینجا بیشتر با اعداد سروکار داشتیم. اما آیا برنامه‌ای که می‌نویسیم فقط باید بتواند با اعداد کار کند؟

فرض کن بخواهیم نام یک کاربر را ذخیره کنیم، پیامی به او نمایش دهیم یا متنی را از ورودی دریافت کنیم. آیا می‌توانیم این اطلاعات را هم در Python نمایش دهیم؟

طبیعتاً بله! Python علاوه بر اعداد، می‌تواند دنباله‌ای از نویسه‌ها (Characters) را نیز نگهداری و پردازش کند. به این دنباله‌ها **رشته (String)** می‌گوییم.

اما چرا به آن‌ها String می‌گویند؟

تصور کن تعدادی مهره را با نخ به یکدیگر متصل کرده‌ای. هر مهره به‌تنهایی یک جزء مستقل است، اما وقتی کنار هم قرار می‌گیرند، یک رشته از مهره‌ها تشکیل می‌دهند.

رشته‌ها هم از کنار هم قرار گرفتن نویسه‌ها ساخته می‌شوند؛ به همین دلیل چنین نامی برای آن‌ها انتخاب شده است.

### ساختن یک رشته

برای ایجاد یک String در Python، کافی است دنباله‌ای از نویسه‌ها را داخل علامت نقل‌قول مستقیم (Straight Quotation Marks) قرار دهیم.

برای مثال:

!!! example "Python"

    ```python
    >>> 'Hello'
    ```

    **Output:**

    ```text
    'Hello'
    ```

همچنین می‌توانیم به‌جای نقل‌قول تکی (`'`)، از نقل‌قول دوتایی (`"`) استفاده کنیم:

!!! example "Python"

    ```python
    >>> "world"
    ```

    **Output:**

    ```text
    'world'
    ```

صبر کن بینم! ما `"world"` نوشتیم، اما Python آن را با نقل‌قول تکی نمایش داد. آیا چیزی تغییر کرده است؟

نه. هر دو شکل برای ساختن رشته معتبر هستند و از نظر مقدار تفاوتی ندارند. محیط تعاملی Python هنگام نمایش نتیجه ممکن است از نقل‌قولی استفاده کند که نمایش رشته را واضح‌تر کند.

اما اصلاً چرا دو نوع علامت نقل‌قول در اختیار داریم؟

یکی از دلایل مهم آن، امکان نوشتن رشته‌هایی است که خودشان شامل علامت نقل‌قول یا آپاستروف (Apostrophe) هستند.

برای مثال، در عبارت انگلیسی زیر از آپاستروف استفاده شده است:

	`it's a small world`

اگر بخواهیم این متن را با نقل‌قول تکی محصور کنیم، ممکن است با مشکل مواجه شویم:

!!! example "Python"

    ```python
    >>> 'it's a small world'
    ```

    **Output:**

    ```text
    it's a small world
      ^
	SyntaxError: unterminated string literal (detected at line 1)
    ```

در این حالت، Python تصور می‌کند رشته پس از حرف `t` تمام شده است؛ در نتیجه، ساختار کد معتبر نخواهد بود.

راه ساده‌تر این است که از نقل‌قول دوتایی برای محصور کردن رشته استفاده کنیم:

!!! example "Python"

    ```python
    >>> "it's a small world"
    ```

    **Output:**

    ```text
    "it's a small world"
    ```

به این ترتیب، آپاستروف داخل رشته قرار می‌گیرد و Python آن را با علامت پایان رشته اشتباه نمی‌گیرد.

رشته‌ها فقط شامل حروف نیستند. می‌توانیم فاصله، علائم نگارشی و حتی اعداد را نیز داخل آن‌ها قرار دهیم:

!!! example "Python"

    ```python
    >>> 'Well, '
    ```

    **Output:**

    ```text
    'Well, '
    ```

در این مثال، علاوه بر حروف، یک کاما و یک فاصله نیز بخشی از رشته هستند.

یک نکتهٔ مهم را هم فراموش نکن: وقتی مقداری را داخل نقل‌قول قرار می‌دهیم، Python آن را به‌عنوان یک String در نظر می‌گیرد؛ حتی اگر محتوای آن شبیه عدد باشد.

برای مثال:

!!! example "Python"

    ```python
    >>> 42
    ```

    **Output:**

    ```text
    42
    ```

یک مقدار عددی است، اما:

!!! example "Python"

    ```python
    >>> '42'
    ```

    **Output:**

    ```text
    '42'
    ```

یک رشته است.

!!! example "Python"

    ```python
    print(type(42))
    print(type('42'))
    ```

    **Output:**

    ```text
    <class 'int'>
	<class 'str'>
    ```
    
این دو ممکن است از نظر ظاهری شبیه باشند، اما از نظر نوع داده و عملیاتی که می‌توان روی آن‌ها انجام داد، تفاوت دارند.

### عملیات روی رشته‌ها

حالا که می‌دانیم String چیست، یک سؤال جدید مطرح می‌شود: آیا می‌توانیم همان عملگرهای حسابی را روی رشته‌ها نیز استفاده کنیم؟

برای مثال، اگر دو رشته را با علامت `+` به یکدیگر متصل کنیم، چه اتفاقی می‌افتد؟

!!! example "Python"

    ```python
    >>> 'Well, ' + "it's a small " + 'world.'
    ```

    **Output:**

    ```text
    "Well, it's a small world."
    ```

خروجی:



در اینجا علامت `+` به‌جای جمع عددی، رشته‌ها را به یکدیگر متصل می‌کند.

به این عملیات **الحاق رشته‌ها (String Concatenation)** می‌گوییم.

پس معنای یک عملگر همیشه مستقل از نوع داده‌هایی نیست که روی آن‌ها استفاده می‌شود. برای مثال، `+` روی اعداد عملیات جمع انجام می‌دهد، اما روی رشته‌ها باعث اتصال آن‌ها می‌شود.

عملگر `*` نیز می‌تواند با رشته‌ها کار کند. اما این بار چه رفتاری از آن انتظار داریم؟

اگر ضرب را برای اعداد به معنای تکرار یک مقدار در نظر بگیریم، می‌توانیم از همین ایده برای رشته‌ها استفاده کنیم: یک رشته را چند بار تکرار کنیم.

برای مثال:

!!! example "Python"

    ```python
    >>> 'Spam, ' * 4
    ```

    **Output:**

    ```text
    'Spam, Spam, Spam, Spam, '
    ```

خروجی:



در اینجا Python رشتهٔ `'Spam, '` را چهار بار تکرار کرده و نسخه‌های آن را به یکدیگر متصل کرده است.

البته این عملیات زمانی معتبر است که رشته را در یک عدد صحیح ضرب کنیم. برای مثال، عبارت `'Spam' * 2.5` معتبر نیست؛ چون Python نمی‌تواند یک رشته را دو و نیم بار تکرار کند!


!!! example "Python"

    ```python
    >>> 'behdad' * 2.5
    ```

    **Output:**

    ```text
    ---------------------------------------------------------------------------
	TypeError                                 Traceback (most recent call last)
	----> 1 'behdad' * 2.5
	
	TypeError: can't multiply sequence by non-int of type 'float'
    ```


همچنین همهٔ عملگرهای حسابی چنین رفتاری ندارند. برای مثال، عملگرهای تفریق و تقسیم را نمی‌توان به شکل معمول روی رشته‌ها استفاده کرد.

!!! example "Python"

    ```python
    >>> 'behdad' - 'hacker'
    ```

    **Output:**

    ```text
	  ---------------------------------------------------------------------------
	TypeError                                 Traceback (most recent call last)
	----> 1 'behdad' - 'hacker'

	TypeError: unsupported operand type(s) for -: 'str' and 'str'
    ```

بنابراین، اینکه یک عملگر روی یک نوع داده قابل استفاده باشد، به این معنا نیست که همان عملگر روی تمام انواع داده‌ها نیز کاربرد دارد.

### طول رشته (String Length)

فرض کن رشته‌ای شامل تعداد زیادی نویسه داشته باشیم. اگر بخواهیم تعداد نویسه‌های آن را به دست بیاوریم، باید تک‌تک آن‌ها را بشماریم؟

خوشبختانه نه! Python برای این کار تابعی به نام `len()` در اختیارمان قرار می‌دهد.

این تابع طول یک رشته را محاسبه می‌کند:

!!! example "Python"

    ```python
    >>> len('Spam')
    ```

    **Output:**

    ```text
    4
    ```

خروجی:



چرا نتیجه `4` است؟

چون رشتهٔ `'Spam'` شامل چهار نویسه است:

```text
S  p  a  m
1  2  3  4
```

> دقت کن که علامت‌های نقل‌قول جزئی از محتوای رشته نیستند؛ آن‌ها فقط برای مشخص کردن ابتدا و انتهای String استفاده می‌شوند. به همین دلیل `len()` آن‌ها را در شمارش خود لحاظ نمی‌کند.
	
> یک نکتهٔ فنی هم وجود دارد: `len()` تعداد کدپوینت‌های Unicode را می‌شمارد، نه لزوماً تعداد نمادهایی که از نظر بصری می‌بینیم. مثلاً بعضی نویسه‌های خاص ممکن است از ترکیب چند کدپوینت ساخته شده باشند. فعلاً لازم نیست درگیر این جزئیات شویم؛ فقط بدان که مفهوم طول رشته همیشه به سادگی شمردن شکل‌های قابل مشاهده نیست.

> ضمناً `len()` فقط برای رشته‌ها نیست؛ این تابع می‌تواند طول مجموعه‌هایی مانند `list`، `tuple` و برخی ساختارهای دادهٔ دیگر را نیز برگرداند.

### انتخاب علامت نقل‌قول صحیح

در پایان، باید به یک نکتهٔ ظاهراً کوچک اما مهم توجه کنیم: علامت‌هایی که برای محصور کردن رشته استفاده می‌کنیم، باید همان علامت‌های معتبر مورد انتظار Python باشند.

برای مثال، نقل‌قول تکی و دوتایی معمولی معتبر هستند اما علامت Backtick یا Backquote که به شکل زیر نوشته می‌شود، برای تعریف String در Python معتبر نیست:

!!! example "Python"

    ```python
    `Hello`
    ```

    **Output:**

    ```text
		`hello`
	    ^
	SyntaxError: invalid syntax
    ```

بنابراین، اجرای این کد باعث ایجاد خطای `SyntaxError` می‌شود.

همچنین باید مراقب **Smart Quotes** یا نقل‌قول‌های خمیده باشیم؛ علامت‌هایی که ممکن است برخی ویرایشگرهای متن به‌صورت خودکار جایگزین نقل‌قول‌های معمولی کنند:

!!! example "Python"

    ```python
    >>> ‘Hello’
    ```

    **Output:**

    ```text
        ‘Hello’
	    ^
	SyntaxError: invalid character '‘' (U+2018)
    ```


!!! example "Python"

    ```python
    >>> “Hello”
    ```

    **Output:**

    ```text
	    “Hello”
	    ^
	SyntaxError: invalid character '“' (U+201C)
    ```
این علامت‌ها با نقل‌قول‌های مستقیم و معمولی Python یکسان نیستند و نمی‌توان از آن‌ها برای تعریف رشته استفاده کرد.

> پس هنگام نوشتن کد، از نقل‌قول‌های مستقیم (`'` و `"`) استفاده کن. اگر دیدی کدی که از یک ویرایشگر متن کپی کرده‌ای بی‌دلیل `SyntaxError` می‌دهد، یکی از چیزهایی که باید بررسی کنی همین نقل‌قول‌های به‌ظاهر بی‌گناه هستند!
