## عملگرهای حسابی (Arithmetic Operators)

فرض کن می‌خواهی دو عدد را با هم جمع کنی. احتمالاً بدون فکر کردن سراغ علامت `+` می‌روی. برای تفریق هم `-`، برای ضرب `×` و برای تقسیم `÷` را انتخاب می‌کنی.

در برنامه‌نویسی هم تقریباً همین کار را انجام می‌دهیم؛ با این تفاوت که به این نمادها **عملگر (Operator)** می‌گوییم.

عملگرها مشخص می‌کنند چه عملیاتی باید روی یک یا چند **عملوند (Operand)** انجام شود.

مثلاً اگر بخواهیم عدد ۳۰ را با ۱۲ جمع کنیم، در Python می‌نویسیم:

!!! example "Python"

    ```python
    >>> 30 + 12
    ```
    
    **Output:**
    
    ```text
    42
    ```

اینجا علامت `+` عملگر جمع است. به همین سادگی!
> علامت `>>>` نشان‌دهندهٔ Python Prompt است؛ یعنی مفسر Python در محیط تعاملی (Interactive Mode) آمادهٔ دریافت دستور جدید است. این علامت بخشی از کد نیست و نباید آن را تایپ کنی؛ فقط دستور بعد از آن را وارد می‌کنی.

**تفریق (Subtraction)** با استفاده از `-`:

!!! example "Python"

    ```python
    >>> 43 - 1
    ```
    
    **Output:**
    
    ```text
    42
    ```
    

**ضرب (Multiplication)** با استفاده از `*`:

!!! example "Python"

    ```python
    >>> 6 * 7
    ```
    
    **Output:**
    
    ```text
    42
    ```

**تقسیم (Division)** با استفاده از `/`:

!!! example "Python"

    ```python
    >>> 84 / 2
    ```
    
    **Output:**
    
    ```text
    42.0
    ```

صبر کن ببینم! چرا نتیجه `42.0` شد؟ مگر ۸۴ تقسیم بر ۲ نمی‌شود ۴۲؟

بله، از نظر ریاضی درست است؛ اما Python یک نکته دارد که باید با آن آشنا شویم.

## انواع دادهٔ عددی (Numeric Types)

Python همهٔ اعداد را به یک شکل در نظر نمی‌گیرد. یکی از تفاوت‌های مهم، تفاوت بین اعداد صحیح و اعداد اعشاری است.

فعلاً با دو نوع عددی مهم سروکار داریم:

- **عدد صحیح (Integer یا `int`):** عددی که بخش اعشاری ندارد؛ مثل `42`، `-7` و `0`.
    
- **عدد ممیز شناور (Floating-Point یا `float`):** عددی که می‌تواند بخش کسری داشته باشد؛ مثل `42.0`، `3.14` و `-2.5`.
    

پس `42` و `42.0` از نظر مقدار ریاضی برابرند، اما نوع دادهٔ آن‌ها در Python متفاوت است.

می‌توانیم این تفاوت را با تابع `type()` بررسی کنیم:

!!! example "Python"

    
    ```python
    print(type(42))
    print(type(42.0))
    ```
    
    **Output:**
    
    ```text
    <class 'int'>
    <class 'float'>
    ```


همان‌طور که می‌بینی، اولی از نوع `int` و دومی از نوع `float` است.

> تابع `print()` برای نمایش خروجی در محیط اجرا استفاده می‌شود. هر مقداری را که به آن بدهی، در خروجی نمایش می‌دهد. مثلاً `print(30 + 12)` ابتدا عبارت را محاسبه می‌کند و سپس نتیجهٔ آن، یعنی `42` را نمایش می‌دهد. برخلاف محیط تعاملی Python، هنگام اجرای کد از داخل یک فایل `.py`، نتیجهٔ عبارت‌ها به‌صورت خودکار نمایش داده نمی‌شود؛ بنابراین برای دیدن خروجی باید از `print()` استفاده کنی.

این تفاوت روی نتیجهٔ عملیات حسابی هم تأثیر می‌گذارد. وقتی دو عدد صحیح را با یکدیگر جمع، تفریق یا ضرب می‌کنیم، نتیجه نیز از نوع `int` خواهد بود. اما **تقسیم معمولی** با **`/`** نتیجه را از نوع `float` برمی‌گرداند؛ حتی اگر حاصل تقسیم دقیقاً یک عدد صحیح باشد.

مثلاً:

!!! example "Python"

    
    ```python
    >>> 84 / 2
    ```
    
    **Output:**
    
    ```text
    42.0
    ```


حالا یک سؤال: اگر بخواهیم تقسیم کنیم، اما نتیجه به شکل عدد صحیح باشد، باید چه کار کنیم؟

آیا Python برای این کار عملگر جداگانه‌ای دارد؟

بله! اسمش `//` است.

## تقسیم صحیح یا کف‌تقسیم (Floor Division)

عملگر `//` تقسیم را انجام می‌دهد، اما نتیجه را به سمت پایین گرد می‌کند. به همین دلیل به آن **Floor Division** یا **کف‌تقسیم** می‌گویند.

مثلاً:

!!! example "Python"

    
    ```python
    >>> 84 // 2
    ```
    
    **Output:**
    
    ```text
    42
    ```
    

این بار نتیجه از نوع `int` است.

اما منظور از «گرد کردن به پایین» دقیقاً چیست؟

فرض کن بخواهیم ۸۵ را بر ۲ تقسیم کنیم:

!!! example "Python"

    
    ```python
    >>> 85 // 2
    ```
    
    **Output:**
    
    ```text
    42
    ```


چرا ۴۲؟ چون حاصل تقسیم معمولی برابر با `42.5` است و `//` آن را به بزرگ‌ترین عدد صحیح کوچک‌تر یا مساوی خودش تبدیل می‌کند؛ یعنی ۴۲.

اما یک نکتهٔ مهم وجود دارد: کف‌تقسیم همیشه به سمت **منفی بی‌نهایت** گرد می‌کند، نه اینکه صرفاً قسمت اعشاری را حذف کند.

برای مثال:

!!! example "Python"


    ```python
    >>> -85 // 2
    ```
    
    **Output:**
    
    ```text
    -43
    ```


> شاید انتظار داشتی جواب `-42` بشه، ولی به `-43` می‌رسی. (استاد اوگوی در پاندای کونگفوکار: شاید دوست داشته باشی سیب بشه ولی به هلو می‌رسی...!) دلیلش این است که کفِ `-42.5` برابر با `-43` است؛ چون `-43` از `-42.5` کوچک‌تر است.

پس حواست باشد: `//` با حذف قسمت اعشاری تفاوت دارد. این تفاوت را به‌خصوص هنگام کار با اعداد منفی فراموش نکن.

خب بهداد، جمع و تقسیم و ضرب و تقسیم و بیخیال. اگر بخواهیم عددی را به توان برسانیم، چه کار می‌کنیم؟

## توان‌رسانی (Exponentiation)

در ریاضیات برای نمایش توان معمولاً از نمادهایی مثل `(7 ^ 2)` استفاده می‌کنیم. در Python برای این کار عملگر `**` را داریم.

مثلاً:

!!! example "Python"

    
    ```python
    >>> 7 ** 2
    ```
    
    **Output:**
    
    ```text
    49
    ```


یعنی ۷ به توان ۲ رسیده است.

> شاید در زبان‌های برنامه‌نویسی دیگری دیده باشی که از علامت `^` برای نمایش توان استفاده می‌کنند. اما مراقب باش! در Python این علامت معنای دیگری دارد.

عملگر `^` در Python برای انجام عملیات **XOR بیتی (Bitwise XOR)** استفاده می‌شود، نه توان‌رسانی.

مثلاً:

!!! example "Python"


    ```python
    >>> 7 ^ 2
    ```
    
    **Output:**
    
    ```text
    5
    ```

بهداد، XOR دیگه چیه؟
