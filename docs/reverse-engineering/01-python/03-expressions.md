## عبارت‌ها (Expressions)

تا اینجا با چند عملگر حسابی آشنا شدیم و دیدیم چطور می‌توانیم با آن‌ها محاسبات مختلفی انجام دهیم. اما اگر چند عملگر را با هم ترکیب کنیم، چه اتفاقی می‌افتد؟

مثلاً به این عبارت نگاه کن:

!!! example "Python"

    ```python
    6 + 6 ** 2
    ```

    **Output:**

    ```text
    42
    ```

اینجا فقط یک عملگر نداریم؛ هم `+` داریم و هم `**`.

به ترکیبی از مقادیر (Values)، عملگرها (Operators) و گاهی اجزای دیگر که Python می‌تواند آن را ارزیابی کند، **عبارت (Expression)** می‌گوییم.

هر عبارت پس از ارزیابی، یک مقدار تولید می‌کند.

مثلاً:

!!! example "Python"

    ```python
    6 * 7
    ```

    **Output:**

    ```text
    42
    ```

یک Expression است که مقدار `42` را تولید می‌کند.

یا این یکی:

!!! example "Python"

    ```python
    30 + 12
    ```

    **Output:**

    ```text
    42
    ```

باز هم یک Expression است و نتیجهٔ ارزیابی آن برابر با `42` خواهد بود.

اما یک سؤال مهم:

وقتی یک عبارت چند عملگر مختلف دارد، Python از کجا می‌فهمد کدام عملیات را باید زودتر انجام دهد؟ آیا می‌توانیم ترتیب انجام محاسبات را هر طور که دلمان خواست تعیین کنیم؟

نه! Python برای ارزیابی عبارت‌ها از مجموعه‌ای از قواعد مشخص به نام **اولویت عملگرها (Operator Precedence)** استفاده می‌کند.

## اولویت عملگرها (Operator Precedence)

احتمالاً از دوران مدرسه با ترتیب انجام عملیات ریاضی آشنا هستی. مثلاً می‌دانیم که توان‌رسانی قبل از ضرب و تقسیم انجام می‌شود و ضرب و تقسیم هم نسبت به جمع و تفریق اولویت دارند.

Python هم قواعد مشابهی دارد.

به مثال زیر توجه کن:

!!! example "Python"

    ```python
    6 + 6 ** 2
    ```

    **Output:**

    ```text
    42
    ```

شاید در نگاه اول فکر کنی Python از چپ به راست محاسبات را انجام می‌دهد؛ یعنی اول ۶ را با ۶ جمع می‌کند و بعد حاصل را به توان ۲ می‌رساند.

اما این‌طور نیست!

عملگر `**` اولویت بیشتری نسبت به `+` دارد. بنابراین Python ابتدا توان را محاسبه می‌کند:

\[
6^2 = 36
\]

بعد نتیجه را با ۶ جمع می‌کند:

\[
6 + 36 = 42
\]

پس خروجی عبارت برابر با `42` است.

یک مثال دیگر:

!!! example "Python"

    ```python
    12 + 5 * 6
    ```

    **Output:**

    ```text
    42
    ```

در اینجا عملگر ضرب `*` نسبت به جمع `+` اولویت بیشتری دارد. بنابراین ابتدا ضرب انجام می‌شود:

\[
5 \times 6 = 30
\]

و بعد:

\[
12 + 30 = 42
\]

حالا فرض کن بخواهیم ترتیب را تغییر دهیم. مثلاً می‌خواهیم ابتدا ۱۲ و ۵ را با هم جمع کنیم و بعد نتیجه را در ۶ ضرب کنیم.

چطور باید این موضوع را به Python بفهمانیم؟

با استفاده از **پرانتز (Parentheses)**!

!!! example "Python"

    ```python
    (12 + 5) * 6
    ```

    **Output:**

    ```text
    102
    ```

وقتی از پرانتز استفاده می‌کنیم، عبارت داخل آن زودتر ارزیابی می‌شود:

\[
\begin{aligned}
12 + 5 &= 17 \\
17 \times 6 &= 102
\end{aligned}
\]

در نتیجه، خروجی برابر با `102` خواهد بود.

پس پرانتز فقط وسیله‌ای برای مرتب‌تر و خواناتر کردن کد نیست؛ بلکه می‌تواند ترتیب انجام عملیات را هم تغییر دهد.

البته لازم نیست تمام عبارت‌ها را با پرانتز بپوشانی! Python خودش قواعد اولویت را می‌داند. اما وقتی می‌خواهی ترتیب خاصی داشته باشی یا خوانایی کد را بیشتر کنی، پرانتز دوست خوب توست.

## هر عبارت یک مقدار دارد

حالا که با عملگرها و عبارت‌ها آشنا شدیم، بیایید یک نکتهٔ مهم را بهتر درک کنیم:

**هر Expression پس از ارزیابی، یک Value تولید می‌کند.**

برای مثال:

!!! example "Python"

    ```python
    6 * 7
    ```

    **Output:**

    ```text
    42
    ```

خود `6 * 7` یک Expression است و مقدار حاصل از ارزیابی آن `42` خواهد بود.

همین موضوع دربارهٔ عبارت‌های پیچیده‌تر هم صدق می‌کند:

!!! example "Python"

    ```python
    (12 + 5) * 6
    ```

    **Output:**

    ```text
    102
    ```

این عبارت هم پس از ارزیابی، مقدار `102` را تولید می‌کند.

بنابراین باید بین خود عبارت و مقداری که از ارزیابی آن به دست می‌آید تفاوت قائل شویم:

- `6 * 7` یک Expression است.
    
- `42` مقدار (Value) حاصل از ارزیابی آن است.
    

این تفاوت در ادامهٔ یادگیری Python اهمیت زیادی پیدا می‌کند؛ چون قرار است با مفاهیمی مثل متغیرها، انتساب (Assignment)، توابع و ارزیابی عبارت‌ها بیشتر سروکار داشته باشیم.

تا اینجا یاد گرفتیم چطور با ترکیب مقادیر و عملگرها، عبارت‌هایی بسازیم که Python آن‌ها را ارزیابی کند و به یک مقدار مشخص برسد.

اما آیا برای انجام محاسبات همیشه باید از عملگرها استفاده کنیم؟

مثلاً اگر بخواهیم یک عدد را گرد کنیم یا قدر مطلق آن را به دست بیاوریم، چه کار باید بکنیم؟

اینجاست که با یکی دیگر از ابزارهای مهم Python آشنا می‌شویم: **تابع‌ها!**

## توابع حسابی (Arithmetic Functions)

تا اینجا برای انجام محاسبات از عملگرهایی مثل `+`، `-`، `*` و `/` استفاده کردیم. اما بعضی عملیات را نمی‌توانیم صرفاً با همین عملگرها انجام دهیم.

فرض کن بخواهیم یک عدد اعشاری را به نزدیک‌ترین عدد صحیح گرد کنیم. آیا برای این کار هم باید دنبال یک عملگر بگردیم؟

نه! Python علاوه بر عملگرها، ابزار دیگری به نام **تابع (Function)** در اختیارمان قرار می‌دهد.

تابع را فعلاً مثل یک ابزار در نظر بگیر که کاری مشخص را برایمان انجام می‌دهد. یک مقدار یا چند مقدار به آن می‌دهیم و تابع عملیات موردنظرش را انجام می‌دهد و ممکن است نتیجه‌ای را برگرداند.

برای مثال، تابع `round()` برای گرد کردن اعداد استفاده می‌شود:

!!! example "Python"

    ```python
    round(42.4)
    ```

    **Output:**

    ```text
    42
    ```

خروجی:



اگر عدد را به `42.6` تغییر دهیم:

!!! example "Python"

    ```python
    round(42.6)
    ```

    **Output:**

    ```text
    43
    ```

خروجی:



پس `round()` عددی را دریافت می‌کند و آن را به نزدیک‌ترین عدد صحیح گرد می‌کند.

البته یک نکتهٔ جالب وجود دارد: اگر عدد دقیقاً بین دو عدد صحیح قرار داشته باشد، Python از روشی به نام **Round Half to Even** استفاده می‌کند.

یعنی در چنین شرایطی، عدد به نزدیک‌ترین عدد صحیح زوج گرد می‌شود.

مثلاً:

!!! example "Python"

    ```python
    round(42.5)
    ```

    **Output:**

    ```text
    42
    ```

خروجی:



و:

!!! example "Python"

    ```python
    round(43.5)
    ```

    **Output:**

    ```text
    44
    ```

خروجی:



چرا؟ چون در مثال اول، ۴۲ و در مثال دوم، ۴۴ عدد زوج نزدیک هستند.

این رفتار ممکن است در نگاه اول کمی عجیب به نظر برسد، اما هدف آن کاهش خطای تجمعی هنگام گرد کردن تعداد زیادی عدد است.

تابع دیگری که برای کار با اعداد استفاده می‌کنیم، `abs()` است.

اما چه زمانی به این تابع نیاز داریم؟

فرض کن بخواهیم فاصلهٔ یک عدد از صفر را محاسبه کنیم. در ریاضیات به این مفهوم **قدر مطلق (Absolute Value)** می‌گوییم.

مثلاً فاصلهٔ عدد `42` از صفر برابر با ۴۲ است. حالا اگر عدد ما `-42` باشد چه؟

باز هم فاصله‌اش از صفر برابر با ۴۲ است.

تابع `abs()` دقیقاً همین کار را انجام می‌دهد:

!!! example "Python"

    ```python
    abs(42)
    ```

    **Output:**

    ```text
    42
    ```

خروجی:



و برای عدد منفی:

!!! example "Python"

    ```python
    abs(-42)
    ```

    **Output:**

    ```text
    42
    ```

خروجی:



پس `abs()` قدر مطلق عدد را برمی‌گرداند.

## فراخوانی تابع (Function Call)

حالا به شکل نوشتن مثال‌های قبلی دقت کن:

!!! example "Python"

    ```python
    print(round(42.4))
    print(abs(-42))
    ```

    **Output:**

    ```text
    42
    42
    ```

در هر دو مثال، ابتدا نام یک تابع را نوشته‌ایم و بعد مقداری را داخل پرانتز قرار داده‌ایم.

به این کار **فراخوانی تابع (Calling a Function)** می‌گوییم. عبارتی که در آن تابع را فراخوانی می‌کنیم نیز یک **Function Call** است.

اما چرا پرانتزها اهمیت دارند؟ آیا می‌توانیم آن‌ها را حذف کنیم؟

بیایید یک آزمایش انجام دهیم:

!!! example "Python"

    ```python
    abs 42
    ```

    **Output:**

    ```text
    SyntaxError
    ```

اگر این کد را اجرا کنی، Python خطایی از نوع زیر نمایش می‌دهد:



این خطا از نوع **خطای نحوی (Syntax Error)** است؛ یعنی چیزی که نوشته‌ایم با قواعد نحوی زبان Python سازگار نیست.

در این مثال، برای فراخوانی تابع باید آرگومان را داخل پرانتز قرار دهیم. شکل صحیح آن این است:

!!! example "Python"

    ```python
    abs(42)
    ```

    **Output:**

    ```text
    42
    ```

اما حالا یک آزمایش جالب‌تر انجام دهیم.

اگر فقط نام تابع را بنویسیم و پرانتزها را حذف کنیم، چه اتفاقی می‌افتد؟

!!! example "Python"

    ```python
    abs
    ```

    **Output:**

    ```text
    <built-in function abs>
    ```

این بار خبری از `SyntaxError` نیست! در محیط تعاملی Python، معمولاً چیزی شبیه به این می‌بینی:



ممکن است ظاهر دقیق خروجی با توجه به محیط یا نسخهٔ Python متفاوت باشد، اما نکتهٔ اصلی این است که Python خود تابع را به ما نشان می‌دهد.

چرا؟

چون نام یک تابع به‌تنهایی هم می‌تواند یک Expression معتبر باشد. در این حالت، Python خود تابع را به‌عنوان یک مقدار در نظر می‌گیرد؛ نه نتیجهٔ اجرای آن را.

پس تفاوت مهمی بین این دو عبارت وجود دارد:

`abs`

و:

`abs(42)`

در حالت اول، به خود تابع اشاره می‌کنیم.

اما در حالت دوم، تابع را با آرگومان `42` فراخوانی می‌کنیم تا عملیات موردنظرش را انجام دهد.

به زبان ساده، نوشتن نام تابع به‌تنهایی مثل این است که آدرس یک ابزار را داشته باشی؛ اما وقتی آن را با پرانتز و آرگومان فراخوانی می‌کنی، در واقع از آن ابزار استفاده کرده‌ای!

این موضوع در Python اهمیت زیادی دارد؛ چون تابع‌ها فقط دستورهایی نیستند که اجرا می‌شوند. خودشان هم مقدار محسوب می‌شوند و می‌توانیم آن‌ها را داخل متغیرها قرار دهیم، به‌عنوان آرگومان به تابع‌های دیگر بدهیم و در موقعیت‌های مختلف از آن‌ها استفاده کنیم.

فعلاً همین تفاوت را به خاطر بسپار؛ بعداً بیشتر با آن سروکار خواهیم داشت.
