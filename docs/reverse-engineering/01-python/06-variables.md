## متغیرها (Variables)

فرض کن می‌خواهی یک مقدار را در برنامه ذخیره کنی تا بعداً بتوانی دوباره از آن استفاده کنی. مثلاً عدد `17` را در نظر بگیر.

می‌توانیم این مقدار را به یک نام متصل کنیم و هر زمان که به آن نیاز داشتیم، از طریق همان نام به آن دسترسی پیدا کنیم.

به چنین نامی در برنامه‌نویسی **متغیر (Variable)** می‌گوییم.

به مثال زیر توجه کن:

!!! example "Python"


	```python
	n = 17
	```


در این دستور، نام `n` را به مقدار `17` متصل کرده‌ایم.

> در پایتون متغیر را نباید صرفاً یک جعبه در حافظه تصور کنیم که مقدار داخل آن قرار گرفته است. مدل ذهنی دقیق‌تر در Python این است که یک Object با مقدار `17` وجود دارد و نام `n` به آن Object اشاره می‌کند. از طریق این نام می‌توانیم به Object موردنظر دسترسی پیدا کنیم. البته این مدل ذهنی برای شروع کافی است؛ جزئیات دقیق‌تر را هنگام مطالعه Python Object Model بررسی می‌کنیم.

## دستور انتساب (Assignment Statement)

برای اتصال یک نام به یک مقدار در Python از دستور **Assignment Statement** استفاده می‌کنیم.

مثلاً:

!!! example "Python"

	
	```python
	n = 17
	```
	

این دستور از سه بخش اصلی تشکیل شده است:

|بخش|مفهوم|
|---|---|
|`n`|نامی که به مقدار متصل می‌شود|
|`=`|Assignment Operator|
|`17`|Expression سمت راست|

در اینجا یک نکته مهم وجود دارد:

علامت `=` در Python برای انتساب استفاده می‌شود، نه مقایسه برابری.

برای مقایسه برابری از `==` استفاده می‌کنیم.

مثلاً:

!!! example "Python"

	
	```python
	>>> n = 17
	>>> n == 17
	```
	
	**Output:**
	
	```text
	True
	```


در دستور اول، نام `n` به مقدار `17` متصل می‌شود.

در دستور دوم، Python بررسی می‌کند که آیا مقدار قابل دسترسی از طریق `n` با `17` برابر است یا خیر.

### Expression در سمت راست Assignment

سمت راست Assignment می‌تواند Expressionهای مختلفی باشد و محدود به یک عدد ساده نیست.

مثلاً:

!!! example "Python"

	
	```python
	n = 17
	pi = 3.141592653589793
	message = 'And now for something completely different'
	```
	

در این مثال‌ها، نام‌های مختلفی را به Objectهایی با انواع متفاوت متصل کرده‌ایم:

- `n` به یک Integer Object اشاره می‌کند.
    
- `pi` به یک Float Object اشاره می‌کند.
    
- `message` به یک String Object اشاره می‌کند.
    

نکته جالب این است که Python یک زبان **Dynamically Typed** است.

یعنی هنگام تعریف متغیر، لازم نیست نوع آن را به‌صورت صریح مشخص کنیم. نوع به Object تعلق دارد و در زمان اجرا مشخص است.

برای مثال، می‌توانیم یک نام را در طول اجرای برنامه به Objectهایی با نوع‌های متفاوت متصل کنیم:

!!! example "Python"
	
	
	```python
	value = 17
	value = 'Hello'
	```
	

در دستور اول، نام `value` به یک Integer Object متصل می‌شود؛ اما در دستور دوم، همین نام به یک String Object متصل می‌شود.

## Assignment خروجی ندارد

وقتی یک Assignment Statement را اجرا می‌کنیم، Python نتیجه‌ای را به‌صورت خودکار نمایش نمی‌دهد.

مثلاً:

!!! example "Python"

	
	```python
	n = 17
	```
	
	**Output:**
	
	```text
	```
	

اما این به معنی انجام نشدن عملیات نیست!

Python دستور را اجرا می‌کند و نام `n` را به Object مربوط به مقدار `17` متصل می‌کند.

حالا می‌توانیم از این نام در Expressionهای دیگر استفاده کنیم.

اگر نام متغیر را به‌تنهایی در محیط تعاملی Python وارد کنیم، مقدار آن نمایش داده می‌شود:

!!! example "Python"

	
	```python
	>>> n
	```
	
	**Output:**
	
	```text
	17
	```


یا می‌توانیم آن را در یک محاسبه به کار ببریم:

!!! example "Python"
	
	
	```python
	>>> n + 25
	```
	
	**Output:**
	
	```text
	42
	```
	

چرا نتیجه `42` است؟

چون Python ابتدا نام `n` را به Object مربوط به مقدار `17` ارزیابی می‌کند و سپس Expression زیر را محاسبه می‌کند:

```python
17 + 25
```

> نمایش خودکار نتیجه Expressionهایی مثل `n` و `n + 25` مربوط به محیط تعاملی Python یا همان REPL است. اگر همین دستورات را داخل یک فایل Python بنویسیم، نتیجه به‌صورت خودکار نمایش داده نمی‌شود و برای نمایش آن باید از `print()` استفاده کنیم.

### استفاده از متغیرها در Expressionها

حالا که با نحوه استفاده از متغیرها آشنا شدیم، می‌توانیم آن‌ها را در Expressionهای مختلف به کار ببریم.

فرض کن متغیرهای زیر را تعریف کرده‌ایم:

```python
pi = 3.141592653589793
message = 'And now for something completely different'
```

حالا می‌توانیم عملیات مختلفی روی آن‌ها انجام دهیم.

**ضرب یک متغیر در عدد:**

!!! example "Python"

	
	```python
	>>> 2 * pi
	```
	
	**Output:**
	
	```text
	6.283185307179586
	```
	

**استفاده از تابع `round()`:**

!!! example "Python"

	
	```python
	>>> round(pi)
	```
	
	**Output:**
	
	```text
	3
	```
	

**استفاده از تابع `len()`:**

!!! example "Python"

	
	```python
	>>> len(message)
	```
	
	**Output:**
	
	```text
	42
	```
	

اینجا با یک مفهوم جدید مواجه می‌شویم: **Argument**.

وقتی یک تابع را فراخوانی می‌کنیم، مقداری را به آن ارسال می‌کنیم تا تابع بتواند روی آن عملیات موردنظرش را انجام دهد. به این مقدار **Argument** می‌گوییم.

مثلاً در دستور زیر:

```
len(message)
```

مقدار قابل دسترسی از طریق `message` به‌عنوان Argument به تابع `len()` ارسال می‌شود.

برای اینکه این مفاهیم را با هم اشتباه نگیریم، تفاوت آن‌ها را ببین:

|مفهوم|مثال|توضیح|
|---|---|---|
|Function|`len`|خود تابع|
|Function Call|`len(message)`|فراخوانی تابع|
|Argument|`message`|مقداری که به تابع ارسال می‌شود|

## نام‌گذاری متغیرها (Variable Names)

تا اینجا از نام‌هایی مثل `n`، `pi` و `message` استفاده کردیم.

اما آیا می‌توانیم هر اسمی را برای یک متغیر انتخاب کنیم؟

خیر! Python برای نام‌گذاری متغیرها قواعد مشخصی دارد.

به‌طور کلی:

1. نام متغیر می‌تواند شامل حروف، اعداد و Underscore باشد.
    
2. نام متغیر نمی‌تواند با عدد شروع شود.
    
3. استفاده از حروف بزرگ و کوچک مجاز است.
    
4. کاراکتر `_` در نام‌گذاری مجاز است.
    
5. نام متغیر می‌تواند طول زیادی داشته باشد.
    

مثلاً نام‌های زیر معتبر هستند:


```python
name = "Behdad"
user_age = 24
counter1 = 10
_private = 100
MAX_SIZE = 4096
```


اما نام‌های زیر معتبر نیستند:


```python
million! = 1000000
76trombones = "big parade"
```


چرا؟

- `million!` شامل کاراکتر غیرمجاز `!` است.
    
- `76trombones` با عدد شروع شده است.
    

### استفاده از Underscore

وقتی نام یک متغیر از چند کلمه تشکیل شده باشد، معمولاً از Underscore برای جدا کردن کلمات استفاده می‌کنیم.

مثلاً:




```python
your_name = "Behdad"
air_speed_of_unladen_swallow = 10
```


> به این سبک نام‌گذاری **snake_case** می‌گویند.
> در این روش، کلمات با حروف کوچک نوشته می‌شوند و برای جدا کردن آن‌ها از Underscore استفاده می‌کنیم.
> این سبک در Python بسیار رایج است و در PEP 8 نیز برای نام‌گذاری متغیرها و توابع توصیه شده است.

## کلمات کلیدی (Keywords)

تا اینجا با قواعد نام‌گذاری متغیرها آشنا شدیم. اما یک محدودیت دیگر هم وجود دارد.

بعضی کلمات در Python از قبل معنای مشخصی دارند و برای ساختارهای خود زبان استفاده می‌شوند. به این کلمات **Keywords** می‌گوییم.

مثلاً فرض کن بخواهیم دستور زیر را اجرا کنیم:

!!! example "Python"
	
	
	```
	class = 'Self-Defence Against Fresh Fruit'
	```
	
	**Output:**
	
	```text
	    class = 'Self-Defence Against Fresh Fruit'
	          ^
	SyntaxError: invalid syntax
	```
	

اما چرا؟

چون `class` یک Keyword است و Python از آن برای تعریف Class استفاده می‌کند. بنابراین نمی‌توانیم از آن به‌عنوان نام متغیر استفاده کنیم.

کلمات دیگری مثل موارد زیر نیز از Keywords زبان Python هستند:

```
if
for
while
class
def
return
import
```


اما اگر نام دیگری انتخاب کنیم، مشکلی وجود ندارد:

!!! example "Python"
	
	
	```python
	class_name = 10
	print(class_name)
	```
	
	**Output:**
	
	```text
	10
	```
	

### مشاهده فهرست Keywords

لازم نیست تمام Keywords زبان Python را حفظ کنی؛ اما باید بدانی این کلمات رزروشده هستند و نمی‌توان از آن‌ها به‌عنوان نام متغیر استفاده کرد.

یک نکته هم وجود دارد: فهرست Keywords ممکن است در نسخه‌های مختلف Python تغییر کند.

برای مشاهده فهرست دقیق Keywords در نسخه نصب‌شده Python، می‌توانیم از ماژول `keyword` استفاده کنیم.


!!! example "Python"

	
	```python
	import keyword  
  
	print(keyword.kwlist)
	```
	
	**Output:**
	
	```text
	['False', 'None', 'True', 'and', 'as', 'assert', 'async', 'await', 'break', 'class', 'continue', 'def', 'del', 'elif', 'else', 'except', 'finally', 'for', 'from', 'global', 'if', 'import', 'in', 'is', 'lambda', 'nonlocal', 'not', 'or', 'pass', 'raise', 'return', 'try', 'while', 'with', 'yield']
	```


این دستور فهرست Keywords را نمایش می‌دهد.

همچنین اگر بخواهیم بررسی کنیم که یک کلمه Keyword است یا نه، می‌توانیم از تابع `iskeyword()` استفاده کنیم.

!!! example "Python"

	
	```python
	import keyword
	
	print(keyword.iskeyword("class"))
	print(keyword.iskeyword("class_name"))
	```
	
	**Output:**
	
	```text
	True
	False
	```
	

همان‌طور که می‌بینی، `class` یک Keyword است؛ اما `class_name` چنین محدودیتی ندارد.
