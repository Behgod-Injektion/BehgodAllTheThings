  

## ساخت لیستی از کلمات (Making a Word List)

در بخش قبلی، فایل `words.txt` را خواندیم و کلماتی را که ویژگی خاصی داشتند، جست‌وجو کردیم؛ مثلاً کلماتی که حرف `e` در آن‌ها وجود داشت.

اما یک مشکل وجود داشت: برای هر جست‌وجو، کل فایل را دوباره می‌خواندیم. این کار چندان بهینه نیست؛ به‌خصوص وقتی قرار است چندین جست‌وجوی مختلف انجام دهیم.

راه بهتر این است که فایل را فقط یک بار بخوانیم و تمام کلمات آن را داخل یک لیست ذخیره کنیم.

برای این کار می‌توانیم از حلقهٔ زیر استفاده کنیم:

!!! example "Python"

	```python
	word_list = []
	
	for line in open('words.txt'):
	    word = line.strip()
	    word_list.append(word)
	
	len(word_list)
	```
	
	**Output:**
	
	```text
	113783
	```


قبل از شروع حلقه، متغیر `word_list` را با یک لیست خالی مقداردهی اولیه می‌کنیم.

در هر تکرار، یک خط از فایل خوانده می‌شود. سپس با استفاده از `strip()` کاراکترهای خالی ابتدا و انتهای آن، از جمله خط جدید (`\n`)، حذف می‌شوند و کلمهٔ حاصل در متغیر `word` قرار می‌گیرد.

در نهایت، متد `append()` آن کلمه را به انتهای لیست `word_list` اضافه می‌کند.

بعد از پایان حلقه، تمام کلمات فایل درون لیست قرار گرفته‌اند. همان‌طور که خروجی `len()` نشان می‌دهد، این لیست شامل ۱۱۳٬۷۸۳ کلمه است!

البته راه دیگری هم برای انجام این کار وجود دارد.

می‌توانیم به‌جای خواندن فایل خط‌به‌خط، با استفاده از متد `read()` تمام محتوای آن را یک‌جا بخوانیم و در قالب یک رشته ذخیره کنیم:

!!! example "Python"

````
```python
string = open('words.txt').read()
len(string)
```

**Output:**

```text
1016511
```
````

این بار به‌جای یک لیست از کلمات، یک رشتهٔ واحد داریم که بیش از یک میلیون کاراکتر دارد.

حالا برای تبدیل این رشته به لیستی از کلمات، کافی است از متد `split()` استفاده کنیم:

!!! example "Python"

````
```python
word_list = string.split()
len(word_list)
```

**Output:**

```text
113783
```
````

همان‌طور که می‌بینی، نتیجه با روش قبلی یکسان است؛ یعنی لیست ما همچنان شامل ۱۱۳٬۷۸۳ کلمه است.

حالا که تمام کلمات را در یک لیست داریم، می‌توانیم با استفاده از عملگر `in` بررسی کنیم که آیا یک کلمه در این لیست وجود دارد یا نه.

مثلاً:

!!! example "Python"

````
```python
'demotic' in word_list
```

**Output:**

```text
True
```
````

پس کلمهٔ `demotic` در لیست وجود دارد.

اما اگر کلمه‌ای را جست‌وجو کنیم که در لیست نیست، نتیجه چه خواهد بود؟

!!! example "Python"

````
```python
'contrafibularities' in word_list
```

**Output:**

```text
False
```
````

این کلمه در لیست پیدا نشده است.

و راستش را بخواهی، من هم از این موضوع کمی _anaspeptic_ هستم! 😄

## اشکال‌زدایی (Debugging)

یک نکتهٔ بسیار مهم دربارهٔ متدهای لیست وجود دارد که باید به آن توجه کنیم:

بیشتر متدهای لیست، خود لیست را تغییر می‌دهند و در مقابل، مقدار `None` را برمی‌گردانند.

این رفتار با متدهای رشته‌ای تفاوت دارد. متدهای رشته‌ای معمولاً یک رشتهٔ جدید برمی‌گردانند و رشتهٔ اصلی را بدون تغییر باقی می‌گذارند؛ چون رشته‌ها Immutable هستند.

مثلاً در کار با رشته‌ها ممکن است چنین کدی بنویسیم:

!!! example "Python"

````
```python
word = 'plumage!'
word = word.strip('!')
word
```

**Output:**

```text
'plumage'
```
````

در اینجا `strip()` یک رشتهٔ جدید برمی‌گرداند و ما آن را دوباره در متغیر `word` ذخیره می‌کنیم.

حالا ممکن است وسوسه شویم هنگام کار با لیست‌ها هم دقیقاً همین الگو را به کار ببریم:

!!! example "Python"

````
```python
t = [1, 2, 3]
t = t.remove(3)  # WRONG!
```
````

اما این کار اشتباه است!

چرا؟

چون `remove()` خود لیست را تغییر می‌دهد و مقدار بازگشتی آن `None` است. بنابراین بعد از اجرای این دستور، متغیر `t` دیگر به لیست اشاره نمی‌کند؛ بلکه مقدار `None` را در خود نگه می‌دارد.

حالا اگر بخواهیم دوباره متدی از لیست را روی `t` اجرا کنیم، با خطا مواجه می‌شویم:

!!! example "Python"

````
```python
t.remove(2)
```

**Output:**

```text
AttributeError: 'NoneType' object has no attribute 'remove'
```
````

شاید پیام خطا در نگاه اول کمی عجیب به نظر برسد. بیایید آن را دقیق‌تر بررسی کنیم.

**Attribute** به ویژگی یا عضوی از یک شیء گفته می‌شود که می‌تواند یک متغیر یا متد مرتبط با آن شیء باشد.

در این مثال، مقدار `t` برابر با `None` است. نوع این مقدار در Python برابر با `NoneType` است.

از طرف دیگر، شیء `None` متدی به نام `remove` ندارد. بنابراین وقتی می‌خواهیم `t.remove(2)` را اجرا کنیم، Python نمی‌تواند چنین متدی را پیدا کند و خطای `AttributeError` ایجاد می‌شود.

پس اگر با خطایی شبیه این مواجه شدی:

```
AttributeError: 'NoneType' object has no attribute ...
```

یکی از اولین کارهایی که باید انجام بدهی این است که کدهای قبلی را بررسی کنی و ببینی آیا به‌اشتباه نتیجهٔ بازگشتی یک متد تغییردهندهٔ لیست را دوباره در همان متغیر ذخیره کرده‌ای یا نه.

**یادت باشد:** برای متدهایی مثل `append()`، `extend()` و `remove()` معمولاً نیازی نیست نتیجهٔ فراخوانی را دوباره به متغیر لیست نسبت بدهی؛ این متدها خود لیست را تغییر می‌دهند.
