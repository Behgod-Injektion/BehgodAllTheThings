  

## لیست‌ها و رشته‌ها (Lists and Strings)

رشته (String) دنباله‌ای از کاراکترهاست و لیست (List) دنباله‌ای از مقادیر؛ اما یک لیست از کاراکترها با یک رشته تفاوت دارد.

فرض کن بخواهیم یک رشته را به لیستی از کاراکترهای تشکیل‌دهنده‌اش تبدیل کنیم. برای این کار می‌توانیم از تابع `list()` استفاده کنیم:

!!! example "Python"

````
```python
s = 'spam'
t = list(s)
t
```

**Output:**

```text
['s', 'p', 'a', 'm']
```
````

تابع `list()` رشته را به کاراکترهای جداگانه تقسیم می‌کند و هر کاراکتر را به‌عنوان یک عنصر در لیست قرار می‌دهد.

اما اگر بخواهیم رشته را به‌جای کاراکترها، بر اساس کلمات جدا کنیم، چه کار باید بکنیم؟

برای این کار می‌توانیم از متد `split()` استفاده کنیم:

!!! example "Python"

````
```python
s = 'pining for the fjords'
t = s.split()
t
```

**Output:**

```text
['pining', 'for', 'the', 'fjords']
```
````

متد `split()` رشته را به بخش‌های جداگانه تقسیم می‌کند و نتیجه را به شکل یک لیست برمی‌گرداند.

به‌صورت پیش‌فرض، فاصله‌های خالی (Whitespace) مرز جدا شدن بخش‌ها در نظر گرفته می‌شوند.

اما همیشه قرار نیست کلمات با فاصله از هم جدا شده باشند. گاهی لازم است خودمان مشخص کنیم که رشته بر اساس چه کاراکتری تقسیم شود.

برای این کار می‌توانیم یک آرگومان اختیاری به نام **Delimiter** یا جداکننده به `split()` بدهیم.

مثلاً فرض کن رشته‌ای داریم که دو بخش آن با خط تیره از هم جدا شده‌اند:

!!! example "Python"

````
```python
s = 'ex-parrot'
t = s.split('-')
t
```

**Output:**

```text
['ex', 'parrot']
```
````

در این مثال، کاراکتر `-` به‌عنوان جداکننده استفاده شده است؛ بنابراین رشته از محل خط تیره به دو بخش تقسیم می‌شود.

حالا برعکس این عملیات را در نظر بگیر. اگر یک لیست از رشته‌ها داشته باشیم و بخواهیم آن‌ها را به یک رشتهٔ واحد تبدیل کنیم، چه کار می‌کنیم؟

برای این کار متد `join()` را داریم.

نکتهٔ جالب اینجاست که `join()` یک متد متعلق به رشته‌هاست، نه لیست‌ها. بنابراین باید آن را روی رشته‌ای که قرار است نقش جداکننده را داشته باشد فراخوانی کنیم و لیست را به‌عنوان آرگومان به آن بدهیم:

!!! example "Python"

````
```python
delimiter = ' '
t = ['pining', 'for', 'the', 'fjords']
s = delimiter.join(t)
s
```

**Output:**

```text
'pining for the fjords'
```
````

در این مثال، مقدار `delimiter` یک کاراکتر فاصله است؛ بنابراین `join()` کلمات را با یک فاصله به یکدیگر متصل می‌کند.

اگر بخواهیم رشته‌ها را بدون هیچ فاصله یا جداکننده‌ای به هم متصل کنیم، می‌توانیم از یک رشتهٔ خالی (`''`) استفاده کنیم.

## پیمایش لیست (Looping Through a List)

همان‌طور که می‌توانیم با استفاده از حلقهٔ `for` روی کاراکترهای یک رشته پیمایش کنیم، برای پیمایش عناصر یک لیست هم می‌توانیم از همین حلقه استفاده کنیم.

فرض کن لیستی از نام چند نوع پنیر داریم و می‌خواهیم تک‌تک عناصر آن را نمایش دهیم:

!!! example "Python"

````
```python
for cheese in cheeses:
    print(cheese)
```

**Output:**

```text
Cheddar
Edam
Gouda
```
````

در هر تکرار، متغیر `cheese` یکی از عناصر لیست را دریافت می‌کند و دستور `print()` مقدار آن را نمایش می‌دهد.

مثلاً می‌توانیم ابتدا یک رشته را با `split()` به لیستی از کلمات تبدیل کنیم و بعد با حلقهٔ `for` روی کلمات آن پیمایش کنیم:

!!! example "Python"

````
```python
s = 'pining for the fjords'

for word in s.split():
    print(word)
```

**Output:**

```text
pining
for
the
fjords
```
````

همان‌طور که می‌بینی، لازم نیست حتماً لیست را از قبل در یک متغیر ذخیره کنیم. می‌توانیم نتیجهٔ اجرای `split()` را مستقیماً در عبارت `for` قرار دهیم.

یک نکتهٔ مهم دیگر: اگر لیست خالی باشد، حلقهٔ `for` حتی یک بار هم اجرا نمی‌شود.

!!! example "Python"

````
```python
for x in []:
    print('This never happens.')
```
````

در این مثال، چون لیست هیچ عنصری ندارد، متغیر `x` هیچ مقداری دریافت نمی‌کند و دستور `print()` هم اجرا نخواهد شد.

## مرتب‌سازی لیست‌ها (Sorting Lists)

گاهی لازم است عناصر یک لیست را مرتب کنیم. برای این کار Python یک تابع داخلی به نام `sorted()` در اختیارمان قرار می‌دهد.

این تابع عناصر لیست را مرتب می‌کند و یک لیست جدید شامل عناصر مرتب‌شده برمی‌گرداند.

مثلاً:

!!! example "Python"

````
```python
scramble = ['c', 'a', 'b']
sorted(scramble)
```

**Output:**

```text
['a', 'b', 'c']
```
````

اما یک نکتهٔ مهم وجود دارد: تابع `sorted()` لیست اصلی را تغییر نمی‌دهد؛ بلکه یک لیست جدید برمی‌گرداند.

برای اینکه مطمئن شویم، می‌توانیم دوباره مقدار لیست اصلی را بررسی کنیم:

!!! example "Python"

````
```python
scramble
```

**Output:**

```text
['c', 'a', 'b']
```
````

همان‌طور که می‌بینی، ترتیب عناصر لیست اصلی همچنان بدون تغییر باقی مانده است.

تابع `sorted()` فقط مخصوص لیست‌ها نیست و می‌تواند با انواع دیگر دنباله‌ها (Sequence) هم کار کند.

مثلاً می‌توانیم کاراکترهای یک رشته را مرتب کنیم:

!!! example "Python"

````
```python
sorted('letters')
```

**Output:**

```text
['e', 'e', 'l', 'r', 's', 't', 't']
```
````

خروجی این عملیات یک لیست از کاراکترهای مرتب‌شده است، نه یک رشته.

حالا اگر بخواهیم نتیجه را دوباره به یک رشته تبدیل کنیم، می‌توانیم از `join()` استفاده کنیم:

!!! example "Python"

````
```python
''.join(sorted('letters'))
```

**Output:**

```text
'eelrstt'
```
````

در این مثال، ابتدا `sorted()` کاراکترهای رشته را مرتب می‌کند و یک لیست برمی‌گرداند. سپس `join()` تمام عناصر آن لیست را به هم متصل می‌کند.

چون از رشتهٔ خالی (`''`) به‌عنوان جداکننده استفاده کرده‌ایم، هیچ فاصله یا کاراکتری بین عناصر قرار نمی‌گیرد.

پس با ترکیب `sorted()` و `join()` می‌توانیم یک رشته را مرتب کنیم و نتیجه را دوباره به شکل یک رشته تحویل بگیریم.
