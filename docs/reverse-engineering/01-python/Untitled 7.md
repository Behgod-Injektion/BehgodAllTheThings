# مقادیر بازگشتی (Return Values)

تا اینجا در مثال‌هایمان از توابع داخلی پایتون، مثل `abs()` و `round()` و همچنین توابع موجود در ماژول `math`، مثل `sqrt()` و `pow()` استفاده کرده‌ایم.

وقتی یکی از این توابع را فراخوانی می‌کنیم، نتیجه‌ای به ما برمی‌گرداند که می‌توانیم آن را در یک متغیر ذخیره کنیم یا به‌عنوان بخشی از یک Expression به کار ببریم.

اما توابعی که خودمان تا اینجا نوشته‌ایم، کمی متفاوت بوده‌اند. بعضی از آن‌ها با استفاده از تابع `print()` مقادیر را نمایش می‌دادند و بعضی دیگر با استفاده از توابع Turtle شکل‌هایی رسم می‌کردند.

در واقع، این توابع مقداری برنمی‌گرداندند که بتوانیم آن را در متغیری ذخیره کنیم یا در یک Expression استفاده کنیم.

در این فصل یاد می‌گیریم چطور تابعی بنویسیم که یک مقدار را به فراخواننده برگرداند.

## بعضی از توابع مقدار بازگشتی دارند

وقتی تابعی مثل `math.sqrt()` را فراخوانی می‌کنیم، نتیجه‌ای که به ما برمی‌گرداند **Return Value** یا مقدار بازگشتی نام دارد.

اگر فراخوانی تابع در انتهای یک Cell در Jupyter قرار بگیرد، Jupyter مقدار بازگشتی آن را بلافاصله نمایش می‌دهد:

!!! example "Python"

    ```python
    import math

    math.sqrt(42 / math.pi)
    ```

    **Output:**

    ```text
    3.656366395715726
    ```

حالا فرض کن بخواهیم نتیجه را در یک متغیر ذخیره کنیم:

!!! example "Python"

    ```python
    radius = math.sqrt(42 / math.pi)
    ```

در این حالت، Jupyter چیزی نمایش نمی‌دهد؛ چون نتیجه به متغیر `radius` اختصاص داده شده است.

اما هر زمان که بخواهیم، می‌توانیم مقدار آن متغیر را نمایش دهیم:

!!! example "Python"

    ```python
    radius
    ```

    **Output:**

    ```text
    3.656366395715726
    ```

حتی می‌توانیم مقدار بازگشتی تابع را مستقیماً در یک Expression استفاده کنیم:

!!! example "Python"

    ```python
    radius + math.sqrt(42 / math.pi)
    ```

    **Output:**

    ```text
    7.312732791431452
    ```

حالا بیایید خودمان تابعی بنویسیم که یک مقدار برگرداند.

فرض کن می‌خواهیم مساحت دایره‌ای را با داشتن شعاع آن محاسبه کنیم:

!!! example "Python"

    ```python
    def circle_area(radius):
        area = math.pi * radius**2
        return area
    ```

تابع `circle_area()` یک Parameter به نام `radius` دریافت می‌کند و با استفاده از آن، مساحت دایره را محاسبه می‌کند.

اما نکته اصلی در خط آخر است:

!!! example "Python"

    ```python
    return area
    ```

این دستور را **Return Statement** می‌نامیم. وظیفه آن برگرداندن مقدار `area` به محلی است که تابع از آنجا فراخوانی شده است.

حالا اگر تابع را به شکل زیر اجرا کنیم، Jupyter مقدار بازگشتی آن را نمایش می‌دهد:

!!! example "Python"

    ```python
    circle_area(radius)
    ```

    **Output:**

    ```text
    42.00000000000001
    ```

مثل قبل، می‌توانیم مقدار بازگشتی را در یک متغیر ذخیره کنیم:

!!! example "Python"

    ```python
    a = circle_area(radius)
    ```

یا مستقیماً از آن در یک Expression استفاده کنیم:

!!! example "Python"

    ```python
    circle_area(radius) + 2 * circle_area(radius / 2)
    ```

    **Output:**

    ```text
    63.000000000000014
    ```

همچنین هر زمان که بخواهیم، می‌توانیم مقدار ذخیره‌شده در متغیر `a` را نمایش دهیم:

!!! example "Python"

    ```python
    a
    ```

    **Output:**

    ```text
    42.00000000000001
    ```

اما یک سؤال: آیا می‌توانیم به متغیر `area` که داخل تابع تعریف کرده‌ایم، از بیرون تابع دسترسی داشته باشیم؟

بیایید امتحان کنیم:

!!! example "Python"

    ```python
    area
    ```

    **Output:**

    ```text
    NameError: name 'area' is not defined
    ```

چرا چنین خطایی رخ می‌دهد؟

چون `area` یک **Local Variable** است؛ یعنی متغیری که داخل بدنه تابع تعریف شده و محدوده دسترسی آن به همان تابع محدود است.

بنابراین نمی‌توانیم مستقیماً از بیرون تابع به آن دسترسی داشته باشیم.

دقت کن که مقدار متغیر `area` از طریق `return area` به بیرون برگردانده می‌شود، اما خود متغیر `area` همچنان یک متغیر محلی باقی می‌ماند.

## بعضی از توابع مقدار None برمی‌گردانند

اگر تابعی دستور `return` نداشته باشد، پایتون به‌صورت پیش‌فرض مقدار ویژه‌ای به نام `None` را برمی‌گرداند.

`None` یک مقدار ویژه در پایتون است؛ درست مثل `True` و `False`.

برای مثال، تابع `repeat()` را که در فصل سوم نوشتیم به خاطر بیاور:

!!! example "Python"

    ```python
    def repeat(word, n):
        print(word * n)
    ```

این تابع با استفاده از `print()` یک String را نمایش می‌دهد، اما هیچ دستور `return` ندارد.

اگر آن را با Argumentهای زیر فراخوانی کنیم:

!!! example "Python"

    ```python
    repeat('Finland, ', 3)
    ```

    **Output:**

    ```text
    Finland, Finland, Finland,
    ```

همان‌طور که می‌بینی، تابع عبارت موردنظر را نمایش می‌دهد. اما نمایش‌دادن یک مقدار با برگرداندن آن تفاوت دارد!

حالا نتیجه فراخوانی تابع را در یک متغیر ذخیره کنیم:

!!! example "Python"

    ```python
    result = repeat('Finland, ', 3)
    ```

    **Output:**

    ```text
    Finland, Finland, Finland,
    ```

با وجود اینکه نتیجه را در متغیر `result` ذخیره کرده‌ایم، تابع همچنان متن را نمایش می‌دهد؛ چون این کار توسط `print()` انجام می‌شود.

حالا اگر مقدار `result` را در Jupyter بررسی کنیم، چیزی نمایش داده نمی‌شود:

!!! example "Python"

    ```python
    result
    ```

اما این به معنی خالی‌بودن متغیر نیست. متغیر `result` واقعاً یک مقدار دارد، ولی Jupyter مقدار `None` را به‌صورت خودکار نمایش نمی‌دهد.

برای اینکه مطمئن شویم، می‌توانیم از `print()` استفاده کنیم:

!!! example "Python"

    ```python
    print(result)
    ```

    **Output:**

    ```text
    None
    ```

پس مقدار بازگشتی تابع `repeat()` برابر با `None` است.

### تفاوت print و return

اینجا باید به یک تفاوت مهم توجه کنیم:

- `print()` مقداری را برای نمایش در خروجی چاپ می‌کند.
    
- `return` مقداری را از تابع به محل فراخوانی آن برمی‌گرداند.
    

این دو کار یکسان نیستند. ممکن است تابعی چیزی را چاپ کند، اما هیچ مقدار مفیدی برنگرداند.

حالا نسخه دیگری از تابع `repeat()` را بنویسیم که به‌جای نمایش مستقیم متن، آن را برگرداند:

!!! example "Python"

    ```python
    def repeat_string(word, n):
        return word * n
    ```

دقت کن که در دستور `return` مجبور نیستیم حتماً نام یک متغیر را بنویسیم؛ می‌توانیم مستقیماً یک Expression را برگردانیم.

حالا نتیجه فراخوانی تابع را در متغیری ذخیره می‌کنیم:

!!! example "Python"

    ```python
    line = repeat_string('Spam, ', 4)
    ```

این بار هنگام اجرای تابع چیزی نمایش داده نمی‌شود؛ چون تابع فقط یک مقدار را برمی‌گرداند و آن مقدار در متغیر `line` ذخیره می‌شود.

بعداً می‌توانیم مقدار متغیر را نمایش دهیم:

!!! example "Python"

    ```python
    line
    ```

    **Output:**

    ```text
    'Spam, Spam, Spam, Spam, '
    ```

این تابع برخلاف نسخه قبلی، چیزی را مستقیماً نمایش نمی‌دهد و اثر جانبی دیگری هم ندارد؛ تنها کاری که انجام می‌دهد، محاسبه و برگرداندن یک مقدار است.

به چنین تابعی **Pure Function** یا تابع خالص می‌گوییم.

در واقع، یک Pure Function مقداری را بر اساس ورودی‌هایش محاسبه می‌کند و برمی‌گرداند، بدون اینکه چیزی را نمایش دهد یا اثر جانبی دیگری داشته باشد.
