## توابع (Functions)

تا اینجا با تعدادی از توابع آمادهٔ Python آشنا شدیم؛ برای مثال، از `int()` و `float()` برای تبدیل نوع داده استفاده کردیم و با توابعی مثل `sqrt()` و `pow()` از ماژول `math` کار کردیم.

اما تا چه زمانی قرار است فقط از توابعی استفاده کنیم که دیگران برایمان نوشته‌اند؟ یکی از قابلیت‌های مهم برنامه‌نویسی این است که بتوانیم **توابع خودمان را تعریف کنیم** و هر زمان که لازم بود آن‌ها را اجرا کنیم.

در این بخش یاد می‌گیریم چطور تابع بسازیم، چطور آن را فراخوانی کنیم و چطور یک تابع می‌تواند تابع دیگری را اجرا کند.

همچنین با دستور جدیدی به نام `for` آشنا می‌شویم که برای تکرار یک عملیات استفاده می‌شود.

برای مثال‌ها هم از چند خط ترانهٔ طنزآمیز استفاده می‌کنیم. شاید مثال‌ها چندان جدی به نظر نرسند، اما مفهومی که قرار است یاد بگیریم یکی از پایه‌های اصلی برنامه‌نویسی است.

## تعریف توابع (Defining New Functions)

تعریف یک تابع یعنی مشخص کنیم تابع چه نامی دارد و هنگام فراخوانی، چه دستورهایی باید اجرا شوند.

بیایید با یک مثال ساده شروع کنیم:

!!! example "Python"

    ```python
    def print_lyrics():
        print("I'm a lumberjack, and I'm okay.")
        print("I sleep all night and I work all day.")
    ```

در خط اول از کلمهٔ کلیدی `def` استفاده کرده‌ایم. این کلمه به Python می‌گوید که قصد داریم یک تابع جدید تعریف کنیم.

نام تابع ما `print_lyrics` است. تقریباً هر نام معتبری که بتوانیم برای یک متغیر انتخاب کنیم، می‌تواند نام یک تابع هم باشد.

اما این پرانتزهای خالی بعد از نام تابع چه معنایی دارند؟

```
def print_lyrics():
```

پرانتزها محل قرار گرفتن پارامترهای تابع هستند. خالی بودن آن‌ها یعنی این تابع در حال حاضر هیچ آرگومانی دریافت نمی‌کند.

حالا بیایید ساختار تعریف تابع را دقیق‌تر بررسی کنیم. تعریف یک تابع دو بخش اصلی دارد:

- **Header:** خط اول تعریف تابع که شامل کلمهٔ کلیدی `def`، نام تابع و پرانتزهاست.
    
- **Body:** دستورهایی که بعد از Header قرار می‌گیرند و هنگام فراخوانی تابع اجرا می‌شوند.
    

در مثال ما، خط اول Header و دو دستور `print()` بخش Body هستند.

چند نکته را فراموش نکن:

- Header باید با علامت `:` تمام شود.
    
- دستورهای داخل Body باید نسبت به Header تورفتگی (Indentation) داشته باشند.
    
- قرارداد رایج در Python استفاده از چهار فاصله برای هر سطح تورفتگی است.
    

Body یک تابع می‌تواند شامل هر تعداد دستور و از هر نوعی باشد؛ محدود به `print()` نیست.

### تعریف تابع با اجرای آن تفاوت دارد

اینجا یک نکتهٔ مهم وجود دارد: **تعریف کردن تابع به معنی اجرای آن نیست.**

وقتی کد زیر را اجرا می‌کنیم:

```
def print_lyrics():
    print("I'm a lumberjack, and I'm okay.")
    print("I sleep all night and I work all day.")
```

Python تابعی با نام `print_lyrics` تعریف می‌کند، اما هنوز دستورهای داخل آن اجرا نمی‌شوند.

در واقع، با تعریف تابع یک Function Object ایجاد می‌شود که می‌توانیم به آن ارجاع بدهیم. برای مشاهدهٔ آن کافی است نام تابع را بدون پرانتز بنویسیم:

!!! example "Python"

    ```python
    def print_lyrics():
        print("I'm a lumberjack, and I'm okay.")
        print("I sleep all night and I work all day.")

    print_lyrics
    ```

    **Output:**

    ```text
    <function __main__.print_lyrics()>
    ```

این خروجی نشان می‌دهد که `print_lyrics` یک Function Object است که هیچ آرگومانی دریافت نمی‌کند.

قسمت `__main__` هم نام ماژولی است که تابع در آن تعریف شده است.

حالا که تابع را تعریف کرده‌ایم، چطور می‌توانیم دستورهای داخل آن را اجرا کنیم؟

### فراخوانی تابع (Function Call)

برای اجرای یک تابع باید آن را فراخوانی (Call) کنیم. این کار دقیقاً مشابه فراخوانی توابع آمادهٔ Python است:

!!! example "Python"

    ```python
    def print_lyrics():
        print("I'm a lumberjack, and I'm okay.")
        print("I sleep all night and I work all day.")

    print_lyrics()
    ```

    **Output:**

    ```text
    I'm a lumberjack, and I'm okay.
    I sleep all night and I work all day.
    ```

این بار با نوشتن `print_lyrics()`، تابع را فراخوانی کرده‌ایم و Python دستورهای داخل Body را به ترتیب اجرا کرده است.

به همین سادگی! تعریف تابع، دستورهایی را برای اجرای بعدی آماده می‌کند و فراخوانی آن باعث اجرای همان دستورها می‌شود.

## پارامترها (Parameters)

تا اینجا تابعی تعریف کردیم که هیچ آرگومانی دریافت نمی‌کرد. اما قبلاً با توابعی کار کرده‌ایم که برای انجام وظیفهٔ خود به ورودی نیاز دارند.

مثلاً تابع `abs()` یک عدد دریافت می‌کند و قدرمطلق آن را برمی‌گرداند. تابع `math.pow()` هم دو آرگومان می‌گیرد: یکی برای پایه و دیگری برای توان.

ما هم می‌توانیم توابعی تعریف کنیم که ورودی دریافت کنند.

به مثال زیر توجه کن:

!!! example "Python"

    ```python
    def print_twice(string):
        print(string)
        print(string)
    ```

این بار داخل پرانتز نام `string` را قرار داده‌ایم. به متغیری که در زمان تعریف تابع داخل پرانتز می‌نویسیم، **پارامتر (Parameter)** می‌گویند.

اما مقدار این پارامتر از کجا می‌آید؟

هنگامی که تابع را فراخوانی می‌کنیم، مقداری را به‌عنوان آرگومان (Argument) به آن می‌دهیم. Python این مقدار را به پارامتر مربوطه اختصاص می‌دهد.

برای مثال:

!!! example "Python"

    ```python
    def print_twice(string):
        print(string)
        print(string)

    print_twice('Dennis Moore, ')
    ```

    **Output:**

    ```text
    Dennis Moore,
    Dennis Moore,
    ```

در این فراخوانی، مقدار `'Dennis Moore, '` به پارامتر `string` اختصاص داده می‌شود. سپس دو دستور `print()` اجرا می‌شوند و همان مقدار را دو بار نمایش می‌دهند.

برای درک بهتر، می‌توانیم رفتار این تابع را به شکل ساده‌تری تصور کنیم:

!!! example "Python"

    ```python
    string = 'Dennis Moore, '
    print(string)
    print(string)
    ```

    **Output:**

    ```text
    Dennis Moore,
    Dennis Moore,
    ```

در واقع، هنگام فراخوانی تابع، مقدار آرگومان به پارامتر اختصاص داده می‌شود و سپس دستورهای داخل تابع اجرا می‌شوند.

### استفاده از متغیر به‌عنوان آرگومان

آرگومانی که به تابع می‌دهیم، لزوماً نباید یک مقدار مستقیم مثل رشته یا عدد باشد. می‌توانیم نام یک متغیر را هم به‌عنوان آرگومان استفاده کنیم:

!!! example "Python"

    ```python
    def print_twice(string):
        print(string)
        print(string)

    line = 'Dennis Moore, '
    print_twice(line)
    ```

    **Output:**

    ```text
    Dennis Moore,
    Dennis Moore,
    ```

در این مثال، مقدار متغیر `line` هنگام فراخوانی تابع به پارامتر `string` اختصاص داده می‌شود.

پس فرقی نمی‌کند آرگومان را مستقیماً بنویسیم یا از یک متغیر استفاده کنیم؛ مهم مقداری است که به پارامتر تابع می‌رسد.
