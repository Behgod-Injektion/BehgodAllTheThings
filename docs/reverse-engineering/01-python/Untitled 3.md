# شرط‌ها و بازگشت (Conditionals and Recursion)

تا اینجا برنامه‌هایی نوشته‌ایم که دستورهای آن‌ها به‌ترتیب اجرا می‌شوند. اما همیشه قرار نیست برنامه تمام دستورها را بدون توجه به شرایط اجرا کند.

گاهی لازم است برنامه بر اساس وضعیت فعلی خود تصمیم بگیرد که کدام دستورها را اجرا کند و کدام را نادیده بگیرد. برای همین از دستور `if` استفاده می‌کنیم.

با یادگیری شرط‌ها، می‌توانیم به یکی از ایده‌های قدرتمند در علوم کامپیوتر، یعنی **بازگشت (Recursion)** هم بپردازیم.

اما قبل از آن، سه مفهوم جدید را بررسی می‌کنیم:

- عملگر باقی‌مانده یا Modulus Operator
    
- عبارت‌های بولی (Boolean Expressions)
    
- عملگرهای منطقی (Logical Operators)
    

## تقسیم صحیح و عملگر باقی‌مانده (Integer Division and Modulus)

قبلاً با عملگر تقسیم صحیح یا Floor Division آشنا شدیم. این عملگر با `//` نوشته می‌شود و حاصل تقسیم را به سمت پایین گرد می‌کند.

فرض کن مدت زمان یک فیلم ۱۰۵ دقیقه است و می‌خواهیم بدانیم این زمان معادل چند ساعت و چند دقیقه است.

اگر از تقسیم معمولی `/` استفاده کنیم، نتیجه یک عدد اعشاری خواهد بود:

!!! example "Python"

````
```python
minutes = 105
minutes / 60
```

**Output:**

```text
1.75
```
````

اما معمولاً مدت زمان را به شکل ۱٫۷۵ ساعت بیان نمی‌کنیم؛ بلکه می‌گوییم یک ساعت و مقداری دقیقه.

برای به‌دست آوردن تعداد ساعت‌های کامل، از تقسیم صحیح استفاده می‌کنیم:

!!! example "Python"

````
```python
minutes = 105
hours = minutes // 60
hours
```

**Output:**

```text
1
```
````

حالا می‌دانیم یک ساعت کامل داریم. اما چند دقیقه باقی مانده است؟

می‌توانیم ۶۰ دقیقه را از زمان کل کم کنیم:

!!! example "Python"

````
```python
remainder = minutes - hours * 60
remainder
```

**Output:**

```text
45
```
````

پس ۱۰۵ دقیقه برابر با یک ساعت و ۴۵ دقیقه است.

اما راه ساده‌تری هم وجود دارد! Python عملگری به نام **Modulus Operator** دارد که با علامت `%` نوشته می‌شود و باقی‌ماندهٔ تقسیم دو عدد را برمی‌گرداند.

!!! example "Python"

````
```python
remainder = minutes % 60
remainder
```

**Output:**

```text
45
```
````

به همین سادگی! به‌جای محاسبهٔ دستی باقی‌مانده، می‌توانیم مستقیماً از `%` استفاده کنیم.

### کاربردهای عملگر Modulus

شاید در نگاه اول فکر کنی این عملگر فقط برای محاسبهٔ باقی‌ماندهٔ تقسیم کاربرد دارد؛ اما کاربردهای جالب‌تری هم دارد.

**۱. بررسی بخش‌پذیری اعداد**

فرض کن می‌خواهیم بررسی کنیم عددی بر عدد دیگری بخش‌پذیر است یا خیر.

اگر باقی‌ماندهٔ تقسیم `x` بر `y` برابر صفر باشد، یعنی `x` بر `y` بخش‌پذیر است:

!!! example "Python"

````
```python
x = 20
y = 5

x % y
```

**Output:**

```text
0
```
````

چون باقی‌مانده صفر است، می‌دانیم ۲۰ بر ۵ بخش‌پذیر است.

**۲. استخراج رقم‌های انتهایی عدد**

با استفاده از `%` می‌توانیم رقم یا رقم‌های سمت راست یک عدد را استخراج کنیم.

مثلاً اگر عددی را بر ۱۰ تقسیم کنیم و باقی‌مانده را به دست آوریم، آخرین رقم آن را خواهیم داشت:

!!! example "Python"

````
```python
x = 12345
x % 10
```

**Output:**

```text
5
```
````

اگر به‌جای ۱۰ از ۱۰۰ استفاده کنیم، دو رقم آخر عدد به دست می‌آیند:

!!! example "Python"

````
```python
x = 12345
x % 100
```

**Output:**

```text
45
```
````

**۳. محاسبات ساعت (Clock Arithmetic)**

یکی دیگر از کاربردهای جالب Modulus، محاسباتی است که در ساعت انجام می‌دهیم.

فرض کن رویدادی ساعت ۱۱ صبح شروع می‌شود و سه ساعت طول می‌کشد. زمان پایان آن چه ساعتی خواهد بود؟

اگر مستقیماً ۳ را به ۱۱ اضافه کنیم، به عدد ۱۴ می‌رسیم. اما ساعت ۱۲ ساعته از ۱۲ دوباره به ۱ برمی‌گردد.

اینجاست که `%` به کمکمان می‌آید:

!!! example "Python"

````
```python
start = 11
duration = 3
end = (start + duration) % 12
end
```

**Output:**

```text
2
```
````

پس رویداد ساعت ۲ بعدازظهر تمام می‌شود.

برای مشاهدهٔ ارتباط تقسیم صحیح و باقی‌مانده، مثال زیر را هم بررسی کن:

!!! example "Python"

````
```python
a = 25 // 10
b = 25 % 10

a, b
```

**Output:**

```text
(2, 5)
```
````

در اینجا `//` تعداد دفعاتی را مشخص می‌کند که ۱۰ به‌طور کامل در ۲۵ جا می‌شود و `%` باقی‌مانده را به ما می‌دهد.

## عبارت‌های بولی (Boolean Expressions)

عبارت بولی (Boolean Expression) عبارتی است که نتیجهٔ آن فقط می‌تواند یکی از دو مقدار `True` یا `False` باشد.

برای مثال، عملگر `==` دو مقدار را با یکدیگر مقایسه می‌کند. اگر برابر باشند، `True` و در غیر این صورت `False` برمی‌گرداند.

!!! example "Python"

````
```python
5 == 5
```

**Output:**

```text
True
```
````

و اگر دو مقدار برابر نباشند:

!!! example "Python"

````
```python
5 == 7
```

**Output:**

```text
False
```
````

### تفاوت `=` و `==`

یکی از اشتباهات رایج هنگام برنامه‌نویسی، استفاده از `=` به‌جای `==` است.

این دو عملگر وظایف کاملاً متفاوتی دارند:

- `=` برای انتساب مقدار به یک متغیر استفاده می‌شود.
    
- `==` برای مقایسهٔ دو مقدار استفاده می‌شود.
    

به مثال زیر توجه کن:

!!! example "Python"

````
```python
x = 5
y = 7

x == y
```

**Output:**

```text
False
```
````

در اینجا ابتدا مقدارهای ۵ و ۷ را به متغیرهای `x` و `y` اختصاص داده‌ایم و سپس با `==` بررسی کرده‌ایم که آیا این دو مقدار برابر هستند یا خیر.

نتیجه هم `False` است؛ چون ۵ با ۷ برابر نیست.

### نوع دادهٔ bool

شاید برایت سؤال شده باشد که `True` و `False` دقیقاً چه نوع داده‌ای هستند؟

این دو مقدار به نوع داده‌ای به نام `bool` تعلق دارند. دقت کن که آن‌ها رشته (String) نیستند؛ بلکه مقادیر بولی هستند.

!!! example "Python"

````
```python
type(True)
```

**Output:**

```text
bool
```

```python
type(False)
```

**Output:**

```text
bool
```
````

### عملگرهای رابطه‌ای (Relational Operators)

عملگر `==` یکی از عملگرهای رابطه‌ای است. این عملگرها برای مقایسهٔ مقادیر و بررسی رابطهٔ میان آن‌ها استفاده می‌شوند.

در Python شش عملگر رابطه‌ای اصلی داریم:

|عملگر|مفهوم|
|---|---|
|`==`|برابر است با|
|`!=`|برابر نیست با|
|`>`|بزرگ‌تر از|
|`<`|کوچک‌تر از|
|`>=`|بزرگ‌تر یا مساوی|
|`<=`|کوچک‌تر یا مساوی|

بیایید چند نمونه را با هم بررسی کنیم:

!!! example "Python"

````
```python
x = 5
y = 7

x != y
```

**Output:**

```text
True
```
````

چون ۵ با ۷ برابر نیست، نتیجه `True` است.

!!! example "Python"

````
```python
x > y
```

**Output:**

```text
False
```
````

چون ۵ بزرگ‌تر از ۷ نیست.

!!! example "Python"

````
```python
x < y
```

**Output:**

```text
True
```
````

چون ۵ کوچک‌تر از ۷ است.

!!! example "Python"

````
```python
x >= y
```

**Output:**

```text
False
```
````

چون ۵ نه بزرگ‌تر از ۷ است و نه با آن برابر.

!!! example "Python"

````
```python
x <= y
```

**Output:**

```text
True
```
````

چون ۵ کوچک‌تر از ۷ است.

این مقایسه‌ها پایهٔ تصمیم‌گیری در برنامه هستند. در ادامه، از همین عبارت‌های بولی در دستور `if` استفاده می‌کنیم تا برنامه بتواند بر اساس نتیجهٔ یک شرط، مسیر اجرای متفاوتی را انتخاب کند.
