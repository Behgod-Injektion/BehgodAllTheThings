# BehgodAllTheThings

Welcome to BehgodAllTheThings!

A free and open-source cybersecurity learning project.

## Our Mission

Make cybersecurity education accessible to everyone.

## What Will You Learn?

- Computer Fundamentals
- Programming
- Operating Systems
- Computer Networking
- Cybersecurity Fundamentals
- Offensive Security
- Reverse Engineering
- Exploit Development
- Security Research
- AI and Security

## Learning Philosophy

Understand how things work.
Learn by experimenting.
Build real skills.
Think independently.
